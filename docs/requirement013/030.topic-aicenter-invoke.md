> **厂商 = 一行 provider 配置**：StepFun / DeepSeek / longcat 等 OpenAI 兼容厂商由**通用适配器**承载，**无厂商专用类**；非 OpenAI 兼容的厂商实现对应能力端口（SPI）即插。

## 013.解析与调用链

```
provider 入参 ──(先 id 后 providerCode)──► AiModelProvider（baseUrl/models/status）
api 入参     ──(先 id 后 apiCode，缺省默认启用)──► AiModelProviderApi（apiKey/status）
model 入参   ── **必传**（调用方直传；框架不挑默认、不猜、不校验归属）
能力路由     ── AiCapabilityRegistry.port(capability, providerCode) → 命中的能力端口
产物         ── 图片/语音：本地存储闸 → 生成 → AiMediaStorePort.save → AiMediaRef
```

- **能力由端口实现承载**（`capabilityCode()` + `supports(providerCode)`），**不落表、不声明**；
- **本地存储闸**：图片/语音调用前检测本地实例，无 → WARN 一次 + 拒绝服务；推理（文本）不受约束；
- **生命周期归使用方**：AI 只产生并返回引用，存储只存取，**都不管何时删**。

## 021.E2E 计划（待真机验证）

1. 推理同步：`/chat` 返回内容；`model` 不传 → 400；
2. 推理流式：`/chat/stream` SSE 逐片返回、结束帧正常；
3. 图片：文生图 / 图生图 → 落盘 → 返回 `storageKey` + `url`；
4. 语音：TTS 落盘；ASR（`/recognize`）返回文本（**ASR 的 `/audio/transcriptions` 是否与厂商一致，需实测**）；
5. 本地闸：无 local011 实例时图片/语音 → WARN 一次 + 拒绝；补上后自动恢复；
6. 厂商路由：同一 provider 行换 `model` 即可切换；非 OpenAI 兼容厂商走 SPI。

## 023.风险

- **ASR 兼容性**：通用适配器假设 OpenAI 兼容 `/audio/transcriptions`，厂商差异需适配；
- **流式资源**：SSE 由 `CompletableFuture` 异步消费，未接专用线程池/超时治理；
- **`byte[]` 落盘**：大文件 OOM 风险（大文件流式后续）；
- **密钥安全**：只在服务端用，不落日志、不出参；加密二期；
- **生命周期**：使用方若忘记删除，临时文件会堆积（平台不管，属约定风险）。
