## 011.结论（一句话）

把同步建成**方向无关**的能力：`source EndpointSpec` → `sink EndpointSpec` + `SyncRule`（动态配置）；**本期不实现**，只留概念与端口，现有 `importDataFromSql` 作为其第一个特化。

## 013.概念与端口（域名待定：暂 `datasource`）

```
datasource（暂）
  EndpointSpec        record（ConnectionInfo + dataSet(表/SQL) + readOnly）
  SyncRule            record（source/sink/mapping/key/mode/batch/conflict）
  SyncTask            record（rule + checkpoint/watermark + status）
  SyncSourcePort      readPage(EndpointSpec, SyncRule, page/watermark) → rows
  SyncSinkPort        write(EndpointSpec, SyncRule, rows) → processed
  SyncEnginePort      编排 source→map→sink（+ checkpoint）
```

- **方向无关**：`source`/`sink` 只是端点；外部与本地都是 `EndpointSpec`。
- **规则可动态配置**：未来落 `july_sync_rule` 表（source/sink/mapping/mode/... JSON）。
- **复用数据源方言**：分页读走 [052] 的方言族；写入走方言 `WriterDialect`。
- **映射**：`mapping[]` 即 `sourceColumn → targetColumn`（此前 047「字段对照器」的概念在此回归，但归属同步规则，不进模板）。
