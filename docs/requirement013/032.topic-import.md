## 013.事务与错误

- `ImportUseCase.importXlsx` 调 Provider；字典 `apply` → UseCase `@Transactional` 整单；
- 失败 = fail-fast 抛业务异常 → 事务回滚 → 信封 400；**不**组装 `ImportRowError` 列表。

## 015.依赖

`java17-core011`：`org.apache.poi:poi-ooxml` **5.2.5** + 显式 `commons-compress` **1.26.2**（避免与 MinIO 等传递旧 compress 产生 `NoSuchMethodError`）。

## 017.批大小

`ImportUseCase.BATCH_SIZE = 500`：文档口径与导出一致（非封顶拒绝）；字典导入路径本期**未按批切写**，整包一次 `apply`。
