# 032.topic-import（技术方案）

> 合流 [requirement011/032](../requirement011/032.topic-import.md) + 导出加厚 [025](../requirement011/025.topic-export.md)。

## 011.落点

| 层 | 类 |
|----|-----|
| common | `ExportFormat011.XLSX` · `AuditType011.IMPORT` |
| domain.export | `ExportSheet` · `ExportWorkbook` · `ExportProvider` 多 sheet 默认方法 · `XlsxWorkbookPort` |
| domain.importdata | `ImportProvider` · `ImportBundle` · `ImportSheet` · `ImportResult` · `ImportRowError` |
| application | `ExportUseCase#exportXlsx` · `ImportUseCase` · `ImportProviderRegistry` |
| infrastructure | `XlsxWorkbookCodec011`（poi-ooxml） |
| 字典 | `JulyDictionaryExportProvider` 两 sheet · `JulyDictionaryImportProvider` · `JulyDictionaryUseCase#importWorkbook` · Controller `/import` + `/export?format=xlsx` |

## 013.事务

`ImportUseCase.importXlsx` 调 Provider；字典 `apply` → UseCase `@Transactional` 整单。

## 015.依赖

`java17-infrastructure011`：`org.apache.poi:poi-ooxml` **5.2.5** + 显式 `commons-compress` **1.26.2**（避免与 MinIO 等传递旧 compress 产生 `NoSuchMethodError`）。
