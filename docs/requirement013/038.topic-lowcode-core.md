## 013.关键机制

- **主子整替**：update = 更新主 → 物理删三子 → 重插三子；insert = 插主 → 插三子；
- **级联逻辑删除**：logicDelete = 物理清三子 → 逻辑删主（`@TableLogic`）；
- **子行物理删**：三子 Mapper 加 `@Delete("DELETE FROM ... WHERE pk_mt = #{masterId}")`，绕开 `@TableLogic`——因唯一键 `(pk_mt, code)` 不含 `dr`，逻辑删后重插会同键冲突（实测 400 duplicate key，已修）；
- **校验**：`objectName` 唯一；子 `code` 同对象内唯一；`displayCode` 必须命中一个 `fieldCode`；类型过枚举。
