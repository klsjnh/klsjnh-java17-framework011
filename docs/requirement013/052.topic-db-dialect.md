# 052.topic-db-dialect（目标库方言适配 · 技术方案）

> 阶段：**requirement013（技术方案 · 双源合流唯一落点）** —— 合流 [requirement011/052](../requirement011/052.topic-db-dialect.md)。
> 状态：**本期实现「端口 + 自动路由 + MySQL 实现」**；Oracle/SQLServer 未来。

## 011.结论（一句话）

把目标侧的 **DDL / 写入 / schema / 类型映射** 抽成**方言族端口**，按 `DatabaseType011` **自动路由**；现有 MySQL 实现降为其中一档，调用方（publish/data-sync/runtime）不改。

## 013.技术落点（端口 + 注册表）

```
domain.lowcode011（或 datasource；本期先随 lowcode 引擎）
  DdlDialectPort        generateCreate / generateAddColumns / tableExists / columnsOf
  WriterDialectPort     upsert(table, businessField, rows)
  TypeMapperPort        columnType(FieldType011, length) → 目标列型
  DialectRegistryPort   resolver(DatabaseType011) → 一组方言实现

infrastructure.lowcode011.dialect
  mysql/MySqlDdlDialect      由现 MySqlMetadataDdlGenerator 降格而来
  mysql/MySqlWriterDialect   由现 JdbcTemplateMetadataDataWriter 的 upsert 语句抽出
  mysql/MySqlSchemaDialect   tableExists/columnsOf（information_schema）
  mysql/MySqlTypeMapper
  DialectRegistry011         按 DatabaseType011 选实现（缺省 MySQL）
```

- **现有端口**：`MetadataDdlGeneratorPort` / `MetadataDdlExecutorPort` / `MetadataDataWriterPort` 保留为**消费面**，其实现改为「查注册表 → 委派方言」。
- **自动路由**：由目标连接/对象的 `dbType`（`DatabaseType011`：mysql/oracle/sqlserver/postgresql）决定；缺省 MySQL。
- **MySQL 行为不变**：只是从"硬编码"变为"MySQL 方言"。

## 015.改动清单

| # | 位置 | 改动 |
|---|------|------|
| 1 | `MySqlMetadataDdlGenerator` | 拆分：SQL 生成 → `MySqlDdlDialect`；表存在/列查 → `MySqlSchemaDialect` |
| 2 | `JdbcTemplateMetadataDataWriter` | `ON DUPLICATE KEY UPDATE` 抽到 `MySqlWriterDialect` |
| 3 | `DatasourceDdlExecutor` | 委派 `SchemaDialect`（表/列目录） |
| 4 | publish / data-sync / runtime | 不变（仍依赖端口） |
| 5 | 新增 `DialectRegistry011` + `DatabaseType011` 路由 | 自动适配 |
| 6 | Oracle/SQLServer | **本期不实现**，仅留注册位 |

## 017.风险 / 边界

- **目标数据源**：本期仍主库；「对象表落动态数据源」= 未来（与 [051] 的 `sink EndpointSpec` 合流）。
- **标识符/保留字/大小写**：Oracle 大写、无反引号；SQLServer 方括号。方言内处理。
- **类型映射差异**：`boolean`(MySQL TINYINT)、`text`(Oracle CLOB)、`date`(各库) —— 由 `TypeMapperPort` 收敛。
- **upsert 语法**：MySQL `ON DUPLICATE KEY`；Oracle/SQLServer 用 `MERGE`。

## 019.状态

- **本期实现**（端口+注册表+MySQL 方言，行为不变）；其余留未来。评审后再估是否与 [051] 同批判。
