## 013.能力二：参数化只读分页

- **端口**：`SqlRoutingPort.selectListByPage(dsCode, sql, params, pageIndex, pageSize)`（PreparedStatement 真绑定）；
- **校验**：`SqlGuard011.assertReadOnly(sql)`——`SELECT` 开头、禁 `;`、禁 DDL/DML 关键字；
- **clamp**：`pageSize ∈ [10, 500]`；方言分页 + `COUNT(*)`；
- **端点**：`POST /klsjnh/datasource/julySql/v1/selectByPage`（`{dsCode, sql, params[], pageIndex, pageSize}`）；
- **未来**：非 SELECT 走独立端点 `…/julySql/v1/execute` + 独立权限（分接口放权）。

## 017.能力三：同步 S1（单表）

**表**：`july_sync_rule`（主）+ `july_sync_rule_column`（子）。DDL [docs/sql/july_center_datasource011.sql](../sql/july_center_datasource011.sql)。

**流程**：`SyncEngine011.run(rule)` → `SyncSource011.readPage`（复用参数化分页读）→ 列对照映射 → `SyncSink011.writePage`（本地表 upsert，`INSERT … ON DUPLICATE KEY UPDATE`，标识符白名单 + 反引号）→ 循环至读完。

**端点**（`/klsjnh/datasource/julySync/v1`）：`insert` / `selectListByPage` / `getByCode` / `logicDelete` / `run`。

**口径**：业务键 `sync_key`（目标侧列名，判重）；命中 → UPDATE 全列（源为准），未命中 → INSERT；`conflict=append` 不判重；`options` JSON 预留 S2/S3（`group`/`parent`/`fk`/`rowTransform`）。

## 019.改造点（方言 bug 修复）

| # | 问题 | 修法 |
|---|------|------|
| 1 | SQLServer `OFFSET/FETCH` 缺 `ORDER BY`；派生表带 `ORDER BY` 非法 | 改 **`ROW_NUMBER() OVER(...)`**（2005+）：顶层 `ORDER BY` 移入 `OVER()`，无则 `(SELECT NULL)`；序号回退常量 |
| 2 | `count` 包子查询遇 `ORDER BY` 非法 | `countSql` **下沉方言 SPI**；SQLServer 剥离顶层 `ORDER BY` |
| 3 | 结果泄漏 `KLSJNH_RN` | 执行器过滤保留列 `klsjnh_rn` |

## 023.E2E（真机）

- **只读分页**：MySQL（参数化 `where db_type=?`）/ Oracle / SQLServer（旧版 + 2012）全 200；非 SELECT → 400、含 `;` → 400；
- **同步 S1**：bpm011（Oracle）`TUSER` **4579 行** → 本地 `lc_bpm_user011`，`read=written=4579`、10 页、**6.5 秒**；重复跑幂等；篡改本地 → 重跑被源覆盖（upsert 回写）。

## 025.风险 / 边界

- **写入方言**：sink 目前为 **MySQL**（`ON DUPLICATE KEY UPDATE`），目标固定**本地库**（`targetDsCode` 仅登记）；
- **S2/S3**：主子 / 一对多 / 多源 未实现（`options` 留口子）；
- **权限**：写端点（`execute`）未开放，机制待定；
- **`byte[]`**：大结果集/大正文有 OOM 风险（流式后续）。
