## 013.关键决策（引用）

- 每次查库不缓存；值全 String（300）；**`status` 可由 CRUD 设置（insert / update）与过滤（selectListByPage）**，停用对程序不可见（`getByCode` 返回 null）；`remark`（备注，≤300，可选）随 insert / update 落库；code 不可变——见 011 文档 §017 / §023。
