# 040.topic-metadata-template（元数据模板导入导出）

> 阶段：**requirement011（业务设计与业务要求）**。
> 定位：把低代码对象的元数据（039 的 MetaDTO + 来源信息）做成**自包含 JSON 模板**：取默认骨架 / 导出 / 上传审核 / 部署。给 AI 与外部工具一个**声明式入口**。
> 基础：[038](038.topic-lowcode-core.md)（一主三子）；[039](039.topic-lowcode-designer-runtime.md)（设计/发布/数据/开放 API）。
> 技术方案：[requirement013/040.topic-metadata-template](../requirement013/040.topic-metadata-template.md)
> **状态：已实现并 E2E（2026-09-17）**。

## 011.对象定义（ObjectInfo011）

| param011   | param013 | remark011 |
| ---------- | -------- | --------- |
| objectCode | july_metadata（复用 038 主 + 三子；**不新增表**，模板为请求/响应载荷） | 模板是文件，不落库 |
| objectName | 低代码核心 - 元数据模板 | 归属 `lowcode011` 域 |
| objectUrl  | /klsjnh/lowcode011/julyMetadata/v1 | Swagger 组 `低代码011` |

## 013.模板结构（templateVersion 1.0）

**1 主 3 子**（`july_metadata` + `_field/_display/_service`），另可带 `source` 与 `_guide`：

```json
{
  "templateVersion": "1.0",
  "metaData": {
    "objectName": "bpm_user_tpl", "objectType": "type011", "description": "BPM用户",
    "businessField": "sid", "packageName": "bpm", "routerPath": "/runtime/bpm_user_tpl",
    "remark": "...",
    "source": { "dataSourceCode": "bpm011", "probeSql": "select id sid, userid username, name, status, orgid pk_organization from tuser" }
  },
  "fieldData":   [ { "code": "sid", "name": "业务ID", "fieldType": "string", "length": 33, "notNull": true, "sort": 1 } ],
  "displayData": [ { "code": "sid", "name": "业务ID", "componentType": "input", "displayType": "all", "sort": 1 } ],
  "serviceData": [ { "code": "query", "name": "查询", "objectType": "type011", "paramType": "query", "enabled": true, "sort": 1 } ]
}
```

- **JSON 不支持注释**：说明放在合法字段 `_guide`（默认骨架里给出），上传时未知键忽略。
- `metaData.source` 可选：`deployObject` 会持久化到 `july_metadata.data_source_code / probe_sql`，`downloadTemplate011` 原样带回，供后续 `importDataFromSql`。
- **基列说明**：模板的 `fieldData` **包含平台基列**（`id/status/dr/create_by/update_by/create_time/update_time`）——这是正常且必需的；基列**只允许出现一次**，类型由平台归一。

## 015.接口清单（前缀 /klsjnh/lowcode011/julyMetadata/v1）

| 端点 | 方法 | 入参 | 说明 |
|------|------|------|------|
| /getTemplate011 | GET | 无 | 默认骨架（合法 JSON，`_guide` 内为说明） |
| /downloadTemplate011 | GET | `objectName`(query) | 导出对象（1 主 3 子 + source） |
| /uploadTemplate011 | POST | **multipart 单文件**（part `file`）或 `application/json` body | **审核**：校验 + 预演，**不落库** |
| /deployObject | POST | `{template, overwrite?}` 或 `{objectName}` | **部署**：校验 → 落库 → 发布（建表/ALTER） |

> URL 规约：**禁 path variable**；objectName 走 query 或 body。

## 017.校验规则（审核与部署共用；部署失败即整单拒绝）

| # | 规则 |
|---|------|
| 1 | `objectName` 必填、`^[a-z][a-z0-9_]{0,49}$`（物理表 `lc_<objectName>`） |
| 2 | 子 `code` 在对象内**大小写不敏感唯一**（这条同时拦截"业务字段重名基列"，如再加一个 `status`/`STATUS`） |
| 3 | 基列**允许出现一次**，类型被归一（`id/create_by/update_by`→33、`status/dr`→3、时间→date） |
| 4 | `businessField` 必须存在于 `fieldData`，且**不得是基列**；固定 `string(33)` |
| 5 | `pk_*` 外键列固定 `string(33)` |
| 6 | `fieldType` 过 `FieldType011`；`objectType` 过 `ObjectType011` |
| 7 | `display.code` 必须绑定一个已存在 `fieldCode` |
| 8 | `templateVersion` 受支持（当前 `1.0`） |

## 019.审核与部署语义

- `uploadTemplate011`：返回 `{valid, errors[], warnings[], plan(create|alter), previewDdl}`，**零副作用**；`multipart` 与 `json` 同一套校验。
- `deployObject`：
  - 带 `template` → 校验通过后落库（038 `insert`/`update`，三子整替）、持久化 `source`、再发布；
  - 只带 `objectName` → 直接发布已存在对象（等价 039 `publish`）；
  - 已存在对象需 `overwrite=true`，否则 400；
  - 发布受开关 `krt.lowcode.ddl-execute.enabled` 约束；首建 `CREATE`、后仅 `ADD COLUMN`。
- **建议 AI 流程**：`getTemplate011` → 填 → `uploadTemplate011` 看 `previewDdl` → 人确认 → `deployObject`。

## 020.E2E（助手自测，2026-09-17）

- `getTemplate011` → 骨架（`_guide` + 4 段 + templateVersion）；
- `downloadTemplate011?objectName=bpm_user011` → 1 主 3 子（含基列）；
- **导出→上传往返** → `valid=true`、`plan=alter`；
- 新对象 `bpm_user_tpl` 审核 → `valid=true`、`plan=create`；multipart 上传同样通过；
- 追加业务字段 `status` → `duplicate field code (case-insensitive)`（拦截成功）；
- `deployObject`（bpm_user_tpl）→ `saved=true, published=true, version=0.0.1`，建表 `lc_bpm_user_tpl`（含 `UNIQUE KEY uk_..._sid`），`data_source_code=bpm011` 已持久化；
- `deployObject {objectName=bpm_user011}` → 发布已存在；`overwrite=false` → 400；`overwrite=true` → 更新成功；导出带出 `source`。

## 021.边界外（本期不做）

- 模板**存储/版本库**（不落库，靠 `july_metadata_version` 快照复现）；
- 模板 → 代码/页面生成；
- 跨环境模板迁移编排；
- 菜单/运行页（039 挂起项）。

## 023.决策记录（2026-09-17 定案）

| # | 决策点 | 结论 |
|---|------|------|
| 1 | 模板是否落库 | ✅ 不落库，纯载荷 |
| 2 | 注释形式 | ✅ 合法 JSON + `_guide`（不用 JSONC） |
| 3 | 上传入口 | ✅ multipart 单文件 + JSON body 双入口，同一套校验 |
| 4 | 审核/部署 | ✅ 分两拍：`uploadTemplate011` 审核（零副作用）、`deployObject` 执行 |
| 5 | 审核状态 | ✅ 无状态：deploy 重新校验（幂等、无暂存） |
| 6 | 默认动作 | ✅ 部署默认 `overwrite=false`（已存在 400） |
| 7 | 基列 | ✅ 模板含基列、只允许一次、类型归一；`businessField` 不得为基列 |
