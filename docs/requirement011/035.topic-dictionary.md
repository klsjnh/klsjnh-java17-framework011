## 015.定位边界

| 对象 | 放什么 | 与字典的边界 |
|------|--------|--------------|
| july_config（029） | 运行时可变键值参数 | 单键单值；字典是「一组带标签的候选值」 |
| july_menu（011） | 菜单/权限树 | 树形导航；字典是扁平候选集（本期不做树） |
| july_dictionary（本对象） | 系统级枚举口径（状态、类型、来源等下拉/枚举） | 主表定义「一类」；子表定义「可选值」 |

## 017.业务规则

- `dictionaryCode` 全表唯一（唯一索引兜底 + 保存预检），**不可变**（修改只改名称/排序/状态/备注）；
- 明细 `itemCode` 在**同一字典内唯一**（唯一索引 `(pk_mt, item_code)`）；不同字典可重名；
- 排序：主表、子表均按 `sort_order` **升序**；程序读入口与列表查询一律带排序；
- `status='0'` 停用：对程序读入口不可见（停用的字典 → 无明细返回；停用的明细 → 不返回）；
- **每次查库不缓存**（用户定案，对齐 029）；
- 程序读入口（UseCase 方法，**无 HTTP 端点**）：
  - `getByType(code)` → 启用的字典及其启用明细（按 sort_order 升序）；字典不存在/停用 → null；
  - `getLabel(type, itemCode)` → 明细名称反查（不存在/停用 → null）；
  - `isValidItem(type, itemCode)` → 值合法性校验（供上游写入前预检）；
- **删除约束（定案）**：删除字典主表时若仍存在存活明细 → `400`（先清明细）；不做级联。

## 019.接口清单（管理面，统一信封）

**字典主表**（前缀 /klsjnh/system011/julyDictionary/v1）

| 端点 | 说明 |
|------|------|
| /insert | 新增字典（dictionaryCode 查重） |
| /update | 修改（名称/排序/状态/备注；code 不可变） |
| /logicDelete | 逻辑删除（受删除约束） |
| /getById | 主键查询（GET，含明细） |
| /getByCode | 按编码查询（GET，含明细） |
| /selectListByPage | 分页查询（code/name 模糊 + 状态过滤） |

**字典明细**

| 端点 | 说明 |
|------|------|
| /insertItem | 新增明细（同字典内 itemCode 查重） |
| /updateItem | 修改明细（itemCode 不可变） |
| /logicDeleteItem | 逻辑删除明细（单个） |
| /selectItemListByType | 按字典取明细列表（排序 + 状态过滤） |

程序读取（无 HTTP）：`getByType` / `getLabel` / `isValidItem`（见 §017）。

## 021.边界外（本期不做）

- 缓存层（读多写少规模化后再议，对齐 029）；
- 树形字典（item.parentId，本期扁平）；
- 明细额外展示字段（color / css_class / ext_json）；
- 多语言 / 租户隔离；
- 明细批量删除（`logicDeleteItemBatch`，按需再加）。
