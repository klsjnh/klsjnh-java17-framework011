# 041.topic-ai011-invoke（AI 模型调用 · chat）

> 阶段：**requirement011（业务设计与业务要求）**。
> 定位：`ai011` 域新增「**调用 AI 模型**」能力（不只是配置与探活）：传入模型与密钥（**均支持 id 或 code**），拿到模型回复。供平台内部服务（含 **AI 自开发**）与 HTTP 调用。
> 基础：[036.topic-ai011](036.topic-ai011.md)（模型接入：provider + api 密钥 + testConnection）。
> 技术方案：[requirement013/041.topic-ai011-invoke](../requirement013/041.topic-ai011-invoke.md)
> **状态：已实现并 E2E（2026-09-17）**。

## 011.对象定义（ObjectInfo011）

| param011   | param013 | remark011 |
| ---------- | -------- | --------- |
| objectCode | ai_model_provider（主）+ ai_model_provider_api（密钥子）；**不新增表** | 复用 036 |
| objectName | AI 模型接入 - 调用（chat） | 归属 `ai011` 域 |
| objectUrl  | /klsjnh/ai011/julyAiChat/v1 | Swagger 组 `AI模型接入011` |

## 013.需求

- 平台内需要「直接调 AI」的能力（当前 ai011 只有配置 CRUD + `testConnection`）。
- **入参的模型与密钥都可能是 id 或 code**：调用方不必关心拿的是哪种标识。
- 以 **`longcat`**（美团的 LongCat，OpenAI 兼容）为例：`provider=longcat`，密钥取其 `apiKey`，`model` 取 provider.models 里的一个。
- 用途：**AI 自开发**（平台自己的 AI 调模型做任务）、内部服务调用、以及未来对外。

## 015.能力边界（首版）

| 做 | 不做（后续） |
|----|--------------|
| **非流式 chat/completions**（OpenAI 兼容） | 流式（SSE）、embedding、图片/多模态、function calling |
| 多轮 messages（由调用方给全量） | 会话存储 / 上下文管理 |
| 超时 + 调用审计 + 用量返回 | 限流 / 计费 / 重试策略 |

## 017.解析规则（关键）

- `provider`：**先按 id 查，再按 providerCode 查**（两者都可能）。
- `api`（密钥）：**先按 id 查，再按 apiCode 查**；**缺省取该 provider 的默认启用密钥**（`getDefaultApi`）。
- `model`：可选；缺省取 `provider.models` 列表首个。

## 019.入参 / 出参（HTTP 与程序入口一致）

**入参**
```json
{
  "provider": "longcat",
  "api": "default",
  "model": "longcat-chat",
  "messages": [ { "role": "system", "content": "..." }, { "role": "user", "content": "..." } ],
  "temperature": 0.7,
  "maxTokens": 1024
}
```

**出参**
```json
{
  "providerCode": "longcat",
  "apiCode": "****abcd",
  "model": "longcat-chat",
  "content": "……",
  "finishReason": "stop",
  "usage": { "promptTokens": 12, "completionTokens": 34, "totalTokens": 46 }
}
```
- `apiKey` **绝不出参**（`apiCode` 可回、`apiKey` 打码/省略）。

## 021.业务规则

- 只调**启用**的 provider 与 api；停用 → 400。
- 密钥：仅服务端使用；**不落日志、不出参**。
- 失败：连接/鉴权/超时 → 明确错误（可读 message）。
- 审计：每次调用落审计（`objectCode = providerCode`，动作 `UPDATE`/`INSERT` 之一，内容含 model + token 数，不含 key）。
