# 050.topic-template-formats（低代码模板 · 多格式导入导出）

> 阶段：**requirement011（业务设计与业务要求）**。
> 状态：**已裁决（2026-09-18）· P1 已实现并 E2E**（JSON / CSV / Markdown；XLSX 占位）。
> 关系：扩展 [040 元数据模板](../lowcode011/029.topic-metadata-template.md)（原 JSON-only；技术方案 [req013/040](../requirement013/040.topic-metadata-template.md)）；模板格式是**模型的可交换表示**，与「数据导入」（`importDataFromSql`，数据行）是两回事。

## 011.定位与归属

- **模板 = 低代码模块的一部分**（留在 `lowcode011`，**不**独立成域）。
- 模板是模型的**可交换表示**（对象 + 字段 + 展示 + 服务 + 来源）；**格式**只是编解码。
- **用途只有一个**：用户拿到模板 → 填/改 → **导入（审核）→ 部署发布**。
- **不落库、不版本化**：模板是瞬时载荷；发布历史仍靠 `july_metadata_version` 快照（040 既定）。

## 013.格式矩阵

| 格式 | 定位 | 现状 |
|------|------|------|
| **JSON** | 完整无损、带 `_guide`；AI/程序 | ✅ 现有（040） |
| **CSV** | 表格化、可在 Excel 里人工改 | ⏳ 本期做 |
| **Markdown** | 分段表格、人类可读、利于 diff/评审 | ⏳ 本期做 |
| **XLSX** | 多 sheet、更友好 | ⏳ **只留接口占位**，后做 |

## 015.CSV 形状（裁决：分段单文件）

有序段，段头 `##<段名>`，段内为 CSV（首行表头）：

```
##metaData          ← key,value 两列
objectName,yw_bpmuser011
objectType,type011
description,...
businessField,username        （必填，非 AI → 045）
packageName,...
routerPath,/runtime/...
##fieldData         ← code,name,fieldType,length,notNull,defaultValue,sort
##displayData       ← code,name,align,width,componentType,displayType,param011,sort
##serviceData       ← code,name,description,objectType,paramType,serviceContent,enabled,sort
##source            ← kind,dataSourceCode,sql/prompt（可省）
```

- 段名与 MetaDTO 键同名（`metaData/fieldData/displayData/serviceData`，见 `MetaDtoKey011`），**XLSX 时一 段 = 一 sheet**（无损对应）。
- 编码 **UTF-8**；导出**带 BOM**（Excel 双击不乱码）；导入容忍有/无 BOM。
- 未知段忽略并 `warnings`；缺列/坏行按现有校验报错。

## 017.管道（复用优先）

```
任意格式(bytes) ──TemplateCodec.import──► MetaDTO ──► 现有 validate / reviewTemplate / deployObject
                                          （下游唯一，与 JSON 完全一致）
```

- 导出：`MetaDTO ──TemplateCodec.export──► bytes(file)`。
- **导入严格度**：模板导入属「非 AI」→ 必须有 `businessField`（[045](045.topic-business-field.md)）。

## 019.端点（沿用现有前缀 `/klsjnh/lowcode011/julyMetadata/v1`）

| 端点 | 变更 |
|------|------|
| `GET /getTemplate011` | 不变（默认 JSON 骨架；可加 `format`） |
| `GET /downloadTemplate011?objectName=&format=json\|csv\|xlsx` | **加 `format`**（缺省 `json`），返回对应文件流 |
| `POST /uploadTemplate011`（multipart / JSON） | **按扩展名 / Content-Type 自动识别格式**，审核零副作用 |
| `POST /deployObject` | 不变 |

## 021.未决/边界

- **不做**：模板落库/版本库；模板 → 代码/页面生成；跨环境迁移编排。
- **XLSX 依赖**：待引入 `apache poi-ooxml`（体积大）；本期只放 `XlsxTemplateCodec` 占位（调用返回「未支持」）。
- CSV 解析：自研轻量（引号/换行转义），不引第三方库。
