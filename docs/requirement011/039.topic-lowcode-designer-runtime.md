# 039.topic-lowcode-designer-runtime（低代码设计器与运行时）

> 阶段：**requirement011（业务设计与业务要求）**。
> 决策定案（2026-09-17）：**全链路做** —— 设计 → 探测 → 发布建表（**DDL 执行要**）→ 数据初始化/同步 → 运行时 → 开放 API；保留 **一主三子（预留多子）**；探测**复用 dataservice011**；发布采用**快照 + DRAFT/PUBLISHED 分离**；DDL **首次 `CREATE TABLE IF NOT EXISTS`、之后仅 `ALTER`、禁 `DROP`**；**运行时权限模型单列**；apiKey 打码/轮换；运行时页面要做。小步快跑，**分三期**。
> 基础：[038.topic-lowcode-core](038.topic-lowcode-core.md)（一主三子元数据 CRUD）。
> 技术方案：[requirement013/039.topic-lowcode-designer-runtime](../requirement013/039.topic-lowcode-designer-runtime.md)

## 015.三条核心决策（2026-09-17 定案）

1. **发布快照 + 编辑态分离**：物理表结构由**发布那一刻**的元数据驱动，落 `july_metadata_version`（`object_name + version + payload_json`(MetaDTO 快照) + `physical_table` + `backup_table` + `ddl_text` + `published_at`）。`july_metadata` 是 DRAFT 编辑态（保留 `publish_status` / `version` 作当前指针）；发版后继续改元数据**不动已发布快照**。
2. **DDL 边界**：首次发布 = `CREATE TABLE IF NOT EXISTS`；其后**仅 `ALTER`**（`ADD COLUMN` / `ADD INDEX` / `ADD UNIQUE`）；**禁 `DROP` / `DROP COLUMN` / `MODIFY` / `RENAME`**（列类型/长度变更走「新列 + 数据迁移」，二期评估）。对象表统一前缀（`lc_`）并隔离库/schema；发布幂等、可重入；带开关 `krt.lowcode.ddl-execute.enabled`（默认 false）。
3. **运行时权限模型单列**（对象级 + 操作级），不夹在运行时段落里做；本期运行时先按「已发布对象 + 白名单操作」收敛，权限模型随后单独一期。

## 017.业务规则

- **探测**：只读连接 + 超时 + `maxRows`；复用 `dataservice011` 的 `executeSql`/探针，按返回推断字段类型（`inferFieldData`）。
- **元数据校验**：`displayCode` 必须绑定已存在 `fieldCode`；类型过 `FieldType011`/`ObjectType011`；`objectName` 唯一不可变。
- **发布**：建表/ALTER + 版本 + 备份表 + **BACKUP 审计**；失败必须可重入，不留半开状态。
- **运行时 CRUD**：仅已发布对象；字段白名单 + 全绑定参数 + 服务端按元数据校验（required / 类型 / 长度 / 唯一）+ 动态 `objectCode` 审计。
- **开放 API**：`apiKey` 打码出参、仅轮换首次回明文一次；`allowedOps` 白名单；限流。

## 019.分期（小步快跑，每期可演示/上线/回滚）

| 期 | 主题 | 一条竖切 | 端点 |
|----|------|----------|------|
| **一** | 设计闭环（**零改库**） | 建模 → 探测 → 预览 DDL | `listModels` `load` `save` `probeSql` `buildFromProbe` `probeAndInfer` `saveDraft` `publishMeta` `selectListByPage` `getById` + `previewDdl` |
| **二** | 发布闭环（写库） | `previewDdl → publish → 导入` 一个对象跑通 | `publish` `syncData` `importDataFromSql` `importStatus` |
| **三** | 运行时 + 开放 API | `publishMenu → 运行页 CRUD → 开放 API` | `publishMenu` `listRuntimeMenus` `initialize` + 动态 CRUD + `openApiConfig` `saveOpenApiConfig` `rotateApiKey` |

> 数据模型**一期一次到位**（建 `july_metadata_version` / `july_metadata_open_api` 与 `july_metadata` 发布态列），避免二期 ALTER 折腾；`previewDdl` 与 `publish` **共用同一 DDL 生成器**（一期落地）。

## 021.边界外（本期不做）

- 子表类型扩展（「多子」本期仍固定 field/display/service 三类）；
- 033 → 本模块的元数据导入；
- 行级数据权限 / 字段级脱敏；
- 生产 DDL 自动执行（需 DBA 审核/工单，开关默认关）；
- 对象间关联/外键。
