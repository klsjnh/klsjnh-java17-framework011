## 015.平台机制（注册制，同 JobHandler 模式）

```
java17-common011
  common.enums.ExportFormat011                    JSON("json") / CSV("csv")
java17-domain011
  domain.platform011.export.ExportProvider        契约（端口）：objectCode() + columns() + exportRows(offset, limit)
java17-application011
  application.platform011.export.ExportProviderRegistry  收集容器内全部 Provider Bean（同 JobHandlerRegistry）
  application.platform011.export.ExportUseCase    解析 Provider → 序列化 → EXPORT 审计；行上限 500 代码限死
  application.<域>.<对象>ExportProvider            各业务对象注册（现已 7 个：user / role / menu / config / organization / dictionary / aiModelProvider）
java17-web011
  各业务控制器 @PostMapping("/export")              POST 二进制下载（Content-Disposition；绕过 JSON 信封属设计）
```

- **上限 500 行**（代码限死，越界截断 + WARN）——沿老积累导出铁律；
- **敏感列红线**：Provider 不得携带 password 哈希等敏感列（julyUser Provider 已示范排除）；
- **必须登录**：无 operator → 401（debug 态同样要求——导出是敏感行为）；
- EXPORT 审计：object_code = 对象编码，content 记录"实际导出 / 总行数"；
- 新对象要可导 = 写一个 Provider Bean 注册即生效，平台零改动。

## 017.格式

- JSON：pretty-print + JSR-310 时间可读；
- CSV：UTF-8 BOM（Excel 直开）+ 表头 + 标准转义（逗号/引号/换行）。

## 021.边界外（本期不做）

- Excel(xlsx) 原生格式（需 POI，二期）；
- 异步导出 / 大数据量流式导出 / 导出任务中心；
- 按过滤条件导出（本期全量 alive 行，上限 500）。
