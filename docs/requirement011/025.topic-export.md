## 015.平台机制（注册制）

```
java17-common011
  ExportFormat011                    JSON / CSV / XLSX
java17-domain011
  ExportProvider                     objectCode + columns + exportRows
                                     + sheetSpecs / exportSheetRows（默认单 sheet master）
  ExportSheet / ExportWorkbook       多 sheet 载荷
  XlsxWorkbookPort                   读写 xlsx（实现在 infrastructure）
java17-application011
  ExportProviderRegistry / ExportUseCase
  application.<域>.*ExportProvider
java17-infrastructure011
  XlsxWorkbookCodec011               Apache POI
java17-web011
  业务 Controller /export            **按需挂载**（非标配）；字典打样支持 format=xlsx 二进制下载
```

- **批大小 500**：导出按批从库拉取（循环直到取尽，**不是**总量上限/截断）；导入侧同口径作建议写批，**不因超过 500 行拒绝**；
- **敏感列红线**：Provider 不得携带 password 等；
- **必须登录**：无 operator → 401；
- EXPORT 审计（xlsx/json 路径均在 `ExportUseCase`）；IMPORT 对称见 [032](032.topic-import.md)；
- 新对象可导 = Provider Bean；**HTTP 端点另加**。

## 017.格式

| format | 说明 | 交付状态 |
|--------|------|----------|
| json | 信封内 `ExportResult`（主 sheet 行，兼容旧前端） | ✅ 已挂 `/export` 的 Controller 默认路径 |
| csv | 枚举预留（UTF-8 BOM + 表头，仅主 sheet） | ⏸ **HTTP 未交付**；勿当作已实现能力 |
| xlsx | 多 sheet；表头行 = 列 `code`；主子见下表 | ✅ 字典打样 `format=xlsx` 二进制下载 |

**Sheet 约定**

| Sheet | 用途 |
|-------|------|
| `master` | 主表（扁平对象仅此页）；导出按 `BATCH_SIZE` **DB 分页**拉行 |
| `children` | 子表 + 业务挂接列（如 `dictionaryCode`），禁止裸 `pk_mt`；字典实现为**先内存装配再按批 `subList`**（非 DB `LIMIT/OFFSET`），大表明细需另案 |

> `ExportFormat011.CSV` 仅占位；新对象勿写「已支持 csv 下载」除非补上序列化与 content-type。

## 021.边界外

- 异步导出 / 任务中心 / 按过滤条件导出；
- 全对象强制挂 `/export`；
- Incremental 子资源整包进 xlsx（存储桶等）。
