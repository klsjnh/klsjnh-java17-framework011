## 013.平台机制

```
domain.platform011.importdata
  ImportProvider          objectCode + sheetSpecs + apply(ImportBundle)
  ImportBundle / ImportSheet / ImportResult
  ImportRowError          类型已预留；本期未接入响应体
application.platform011.importdata
  ImportProviderRegistry / ImportUseCase
infrastructure
  XlsxWorkbookCodec011    解码（与导出同源）
```

- 有 Provider = 可被平台导入；**HTTP 另挂**；
- 必须登录；写 **IMPORT** 审计（use case 内；Controller **禁止**再挂 `@AuditLog`）；
- **批大小 500**：与导出同义——建议写批/分页步长，**不是**「超过 500 行整单拒绝」；字典 `importWorkbook` 本期单事务整包应用，常量仅作建议口径；
- 校验/写库失败 → **整单回滚** + **fail-fast** `BusinessException`（400，消息字符串可含定位提示）；**本期不返回**结构化 `ImportRowError[]`。

## 015.冲突与主子

| 项 | 口径 |
|----|------|
| 主表 | 业务键 **upsert** |
| 子表（Replace 型整包） | 文件中出现过的主业务键：该主下子表 **Replace**；未出现的其它主不动 |
| 挂接 | 子 sheet 用业务外键（如 `dictionaryCode`），禁止 `pk_mt` |
| 敏感列 | 忽略/拒收 |

## 017.字典打样

- Provider：`JulyDictionaryImportProvider`（objectCode `julyDictionary`）
- UseCase：`importWorkbook`（upsert 主 + 按出现过的 code Replace 明细）
- HTTP：`POST .../julyDictionary/v1/import`（multipart file）

## 021.边界外

- 全对象 `/import`；仅新增/全量同步删库；异步任务；非 xlsx 格式本期。
