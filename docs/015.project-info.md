# 015 — 项目信息（Project Info）

> 项目事实卡：定位 / 技术栈 / 骨架 / 构建与运行 / 当前能力。版本与键的事实来源是父 `pom.xml` 与 [015.topic-config](infrastructure011/015.topic-config.md)。

## 011.定位

`klsjnh-java17-framework011` —— Java 17 纯血 DDD 技术底座，Maven 多模块，供第三方业务系统 Maven 依赖引用。对外契约（响应信封 / 状态码 / 路由风格 / 公共表结构）稳定，见 [013.api-contract](013.api-contract.md)。

## 017.构建与运行

```bash
./script011.sh gate      # 门禁：编码规范（正则 + AST）+ mvn 离线编译
./script011.sh           # gate → .vf 版本自增（X.Y.Z，patch/minor 满 99 进位）→ commit（ver X.Y.Z）→ push
./script011.sh build011  # mvn clean package install
./script011.sh dev011    # 启动应用：杀进程后直接执行现有 jar（debug 模式）
./script011.sh dev013    # 启动应用：杀进程后重新编译（clean 删旧 jar）再执行
./script011.sh stop|restart|status|log   # 运行态管理
java -jar java17-reference-app011/target/java17-reference-app011-1.0.0.jar   # 11160 端口
```

- 端口 11160；接口文档 `http://127.0.0.1:11160/doc.html`（分组：系统管理011 / IAM011 / 存储中心011 / 数据源011 / AI中心011 / 消息中心011）
- Druid 监控台 `/druid`（仅 dev 启用，klsjnh/klsjnh；⚠ allow 未配置默认只放 127.0.0.1，LAN 访问需显式配 allow，见配置体系文档）
- profile：development（默认，共享配置入库）/ production（部署机自建，不入库）；`krt.status` 见配置体系文档
- 环境依赖：Node 18+（门禁 AST：tree-sitter / tree-sitter-java，用户级 node_modules）· MySQL（docker 容器，宿主 33306）
- **容器化部署**（docker compose / ubuntu 26.04 基镜像 / 落地件 `docs/deploy/`）见 [infrastructure011/020](infrastructure011/020.topic-deploy-docker.md) · [deploy/README](deploy/README.md)

## 019.当前能力（截至 2026-09-24）

- 持久化（2026-09-22/23）：PO 家族（`BasePo` / `BasePo011` / `TreePo` / `TreePo011` / `MasterLinked`）+ 仓库基座（`BaseRepository` / `BaseTreeRepository` / `BaseMasterSubRepository` / `BaseTreeSubRepository`；**排序走 `SortSupport`，无 `*Repository011` 排序基座**）+ 公共件 `TreeAssembler` / `MasterSubSupport` / `SortSupport` + 审计自动填充（时间 + 操作人）；主子三分 API 见 [031/018](infrastructure011/031.persistence-center/018.topic-master-sub-api.md)
- **IAM 中心**（[018](infrastructure011/018.iam-center/011.topic-design.md)）：用户 / 角色 / 菜单树 / 组织 / 用户审计；**权限目录** `july_perm_*` + `assignObjectActions`；`AuthorizationPort` **opt-in**（挂 `assertHas` 才过滤）；julyConfig / julyScheduler 示范已 E2E（详 [016](infrastructure011/018.iam-center/016.topic-dynamic-permission.md)）
- **system011**（非 IAM）：配置（july_config）· 调度（julyScheduler）· 数据字典（july_dictionary）
- 调度：julyScheduler 全链路（Quartz 内存模式，JobHandler 注册器，重启自愈，Demo011Scheduler 30s 演示）
- 动态数据源：yaml ci011 懒加载 + SqlRoutingPort 读写 / **分页方言为开放 SPI**（`SqlDialectPort011` + 注册表，内置 mysql/postgresql/oracle/sqlserver；`dbType` 开放字符串，2026-09-19）/ clamp [10,500] / 标量糖 selectStr / selectInt
- 存储中心：`ObjectStoragePort`（对象 + 桶 CRUD + stat）+ **工厂型 SPI**（`ObjectStorageProviderFactory` + `ObjectStorageProviderRegistry`，内置 local011/minio011/s3011，余由使用者扩展）；**主子表** `july_storage_provider` + `july_storage_provider_bucket`，实例/桶管理面；对象定位元数据见 [016 规约·非平台能力](infrastructure011/011.storage-center/016.topic-object-metadata-convention.md)
- 配置管理：july_config（运行时键值参数，每次查库，getByCode 程序读取入口）
- AI 中心（aicenter，2026-09-20 重构）：provider + api 密钥（主子表）+ testConnection（OpenAI 兼容）
- AI 能力（aicenter，2026-09-20）：**能力 SPI + 通用 OpenAI 兼容适配器**。`AiCapabilityPort` + `AiCapabilityRegistry` 按 (capability, provider) 路由；四能力：`inference`（`AiInferencePort`，同步 + **SSE 流式**）、`image`（`AiImagePort`，文生图/图生图）、`tts`（`AiTtsPort`）、`asr`（`AiAsrPort`，**语音识别**）；产物经 `AiMediaStorePort` 落盘（**调用必传** `storageCode|storageId` + `bucketCode|bucketId`，无默认桶 / 无本地闸）；**model 由调用方直传**（框架不推理）。厂商 = 一行 provider 配置（通用适配器），非 OpenAI 兼容的厂商实现对应 SPI 即插
- 提示词管理（aicenter，2026-09-21 重构）：**主子表** `july_ai_domain`（业务域树，`domain_code` 全局唯一）+ `july_ai_domain_prompt`（提示词，`prompt_code` 全局唯一）；`content` `TEXT`（≤64KB inline，超则落对象存储）；`render(promptCode, params)` 公共件
- 消息中心（messagecenter）：**出入两套**（2026-09-19）。出站 `MessageChannelPort` SPI + `MessageChannelRegistry` + `JulyOutbound{Channel,Template,Message}` 三表 + send/分页/重发 + 内置 `inapp`/`webhook`；入站 `MessageInboundPort`/`InboundMessageListener` SPI + `MessageInboundRegistry` + `JulyInbound{Channel,Template,Message}` 三表 + `receive` 回调入口（去重/落库/分发/被动回复）。`messageType`/`payload` 为开放透传位；厂商渠道（企微/飞书/钉钉/短信）由使用者插件提供，**非框架能力**
- HTTP 工具：`common.util.HttpUtil011`（JDK HttpClient 薄封装：`get`/`getBytes`/`postJson`/`postJsonBytes`/`postJsonStream`/`postMultipart` → `HttpResponse011(status, body)` / `HttpResponseBytes011(status, bytes)`）；框架 `WebhookMessageChannel` / `AiModelProbe011` / 通用 OpenAI 兼容适配器（含推理 SSE 流式）均用它
- 平台导出（025）：注册制 ExportProvider + **json（已交付）/ xlsx（字典打样）**；`csv` 枚举预留、HTTP **未交付**；批大小 500（非总量封顶）+ EXPORT 审计
- 平台导入（032）：注册制 ImportProvider + xlsx；Controller **按需**（字典打样 `/import`）+ IMPORT 审计；失败 fail-fast 整单回滚
- 全局异常 → 统一信封（HTTP 与 statusCode 同步，errorMessage 仅 debug）；`traceId` 经 MDC 贯通
- 参考样板：`com.klsjnh.demo11` DDD 纵切面（第三方照抄入口）

> **DDL 债**：部分业务表 CREATE 仍 `UNIQUE(业务列)`，未统一 `alive_*` 生成列；见执行任务 [031/020](infrastructure011/031.persistence-center/020.topic-alive-unique-ddl-complete.md)。
