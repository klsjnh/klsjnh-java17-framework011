# 011 — center-message011-starter · 消息中心整体体系（starter 版）

> 阶段：**基础设施架构专题** —— 消息中心**完整纵切面**（出入两套 + 管理面）已自 core 剥离、整体入驻本 starter。
> 状态：**已实现（2026-09-25）**。
> DDL：[july_center_message.sql](../../sql/july_center_message.sql)。
> 历史设计（出入两套口径 / 去重 / 分发语义）仍然有效：[013.message-center](../013.message-center/011.topic-design.md)（未改，URL 契约与其一致）。

## 011.命题

**消息中心 = 一个 starter。** `center-message011-starter` 自包含消息中心全部代码：出站（渠道 / 模板 / 消息）、入站（渠道 / 模板 / 消息）与各自管理面。消费方**引 starter 得到全部，不引则整个中心不存在**。

## 013.与 core 的边界（剥离后）

| 归属 | 内容 |
|------|------|
| **本 starter** | `com.klsjnh.domain.messagecenter`（inbound / outbound 的 channel·message·template 聚合与端口）、`application.messagecenter`（两套 UseCase + Registry）、`infrastructure.messagecenter`（PO/Mapper/RepositoryImpl + 内置渠道 `InAppMessageChannel` / `WebhookMessageChannel`）、`web.messagecenter`（6 Controller + Converter + VO） |
| **core011（被本 starter 依赖）** | `common`（HttpUtil011 / HttpResponse* 出站 HTTP 通道；`MessageProviderTypes011` / `MessageStatus011` / `MessageInboundStatus011` 状态与类型常量）、`domain.shared`、审计端口 |
| **不再存在于 core** | 任何 `messagecenter` 代码 —— core 对消息 **零残留** |

> 命名口径：中心类 starter 无 `java17-` 前缀，`center-<名>011-starter`。

## 016.依赖关系

```
center-message011-starter ──► java17-core011 ──► java17-security-api011
（叶子模块：无人依赖本 starter；技术依赖最轻——无任何 SDK）
```

## 019.装配机制

- starter 代码在 `com.klsjnh.*.messagecenter` 包树下，由 core 的 `CoreAutoConfiguration011` 定向扫描**随 classpath 收编**。
- 渠道注册表 `MessageChannelRegistry` / `MessageInboundRegistry` 以 `List<端口>` 收集实现——内置 inapp / webhook 随 starter 提供，厂商渠道实现 SPI 即自动注册。

## 022.能力与端点

| Controller | URL 前缀 | 说明 |
|------------|----------|------|
| `JulyOutboundChannelController` | `/klsjnh/messagecenter/julyOutboundChannel/v1` | 出站渠道管理 |
| `JulyOutboundMessageController` | `/klsjnh/messagecenter/julyOutboundMessage/v1` | 消息发送 / 记录 |
| `JulyOutboundTemplateController` | `/klsjnh/messagecenter/julyOutboundTemplate/v1` | 出站模板（render） |
| `JulyInboundChannelController` | `/klsjnh/messagecenter/julyInboundChannel/v1` | 入站渠道管理 |
| `JulyInboundMessageController` | `/klsjnh/messagecenter/julyInboundMessage/v1` | 接收 / 去重 / 分发 |
| `JulyInboundTemplateController` | `/klsjnh/messagecenter/julyInboundTemplate/v1` | 入站模板 |

## 025.内置渠道与扩展点

| 端口 | 方向 | 内置实现 | 扩展方式 |
|------|------|----------|----------|
| `MessageChannelPort` | 出站 | `InAppMessageChannel`（站内信）/ `WebhookMessageChannel`（HTTP 回调） | 实现 `MessageChannelPort` 注册为 bean，Registry 自动收编 |
| `MessageInboundPort` + `InboundMessageListener` | 入站 | webhook 接收 | 实现 SPI + 监听器 |

> 渠道的 endpoint / 认证等参数全部存于渠道表的 config JSON，管理面可配，厂商渠道零代码接入。

## 028.消费方行为矩阵

| 场景 | 行为 |
|------|------|
| 引 starter | 出入两套全量可用；导 `july_center_message.sql`（6 表） |
| 不引 starter | **`/klsjnh/messagecenter/**` 整体 404（路由级）**；不导 6 表；classpath 零消息代码 |
