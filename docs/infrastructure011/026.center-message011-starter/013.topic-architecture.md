# 013 — center-message011-starter · 系统整体架构

> 四篇一套：[011 设计思路](011.topic-design.md) · 本篇架构 · [015 怎么使用](015.topic-usage.md) · [016 二开手册](016.topic-secondary-dev.md)。

## 011.运行视图（出站发送链路）

```
Client ──JWT──► GlobalAuthFilter ──► JulyOutboundMessageController (web.messagecenter)
                                        │
                                        ▼
                              MessageOutboundUseCase (application.messagecenter.outbound)
                                │            │              │
                        模板 render     MessageChannelRegistry   记录落库
                    （july_outbound_template） （code → 渠道实现）   （july_outbound_message）
                                             │
                              ┌──────────────┴──────────────┐
                              ▼                             ▼
                    InAppMessageChannel             WebhookMessageChannel
                    （站内信落 inbound 表）          HttpUtil011 → 回调地址
```

## 013.入站接收链路

```
外部事件 ──► MessageInboundPort 实现 ──► InboundMessageListener
                                            │
                                    去重（幂等键）
                                            │
                                    分发给业务监听者
                                            │
                                    july_inbound_message 落记录
```

## 015.关键设计件

| 件 | 位置 | 职责 |
|----|------|------|
| `MessageChannelRegistry` | application.outbound.channel | `List<MessageChannelPort>` 自动收编（空 = 中心在但无可用渠道） |
| `MessageInboundRegistry` | application.inbound.channel | 入站对称收编 |
| `MessageOutboundUseCase` | application.outbound.message | render → 路由渠道 → 发送 → 记录（事务边界） |
| `InAppMessageChannel` | infrastructure.outbound.channel | 站内信：写 inbound 消息表 |
| `WebhookMessageChannel` | infrastructure.outbound.channel | HTTP 回调：config JSON（endpoint 等）→ HttpUtil011 |
| `render` / `parseConfig` | use case 私有件 | 模板参数渲染；渠道 config JSON 解析 |

## 021.与框架其他部分的关系

| 关系 | 方向 | 说明 |
|------|------|------|
| HTTP 出口 | 本 starter → `common.util.HttpUtil011` | webhook 回调；SSRF / 出口治理见 [033](../033.topic-platform-security.md) |
| 状态常量 | 本 starter → core common | `MessageStatus011` / `MessageInboundStatus011` / `MessageProviderTypes011` |
| Swagger | core 固定 URL 组 | `messagecenter` 组随 starter 在场展示 |

## 024.语义口径

- **渠道无状态**：所有差异化参数在渠道表 config JSON；实现类不持可变全局状态。
- **幂等**：入站去重靠幂等键唯一约束兜底；业务预检查只做友好提示。
- **记录先行**：发送 / 接收都先落记录再执行结果回填，排查以记录表为准。
