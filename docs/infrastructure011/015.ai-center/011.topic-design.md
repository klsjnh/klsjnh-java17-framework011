## 011.命题

**一套模型接入，三大能力模块。** 框架提供统一的 provider/密钥管理与能力注册表；**推理 / 图片 / 语音**三块能力各自成模块，厂商按能力插拔；生成产物经存储中心落盘；**模型名由调用方直传，框架不推理**。

## 013.三大能力模块

| 模块 | 能力 code | 子能力 | 输入 → 输出 | 产物落盘 | 流式 |
|------|-----------|--------|-------------|----------|------|
| **推理 `inference`**（原 chat） | `inference` | 提示词推理 | prompt → 文本 | 否（纯文本） | ✅ SSE / chunked |
| **图片 `image`** | `image` | 文生图 · 图生图 | prompt（± 输入图）→ 图片 | ✅ 本地 | 否 |
| **语音 `audio`** | `tts` · `asr` | 语音合成 · **语音识别（新增）** | 文本→音频 / 音频→文本 | ✅ 本地（音频） | 可选 |

> **命名**：模块 `inference`（推理），能力 code `inference`（兼容别名 `chat`）。它不止"聊天"——是"给提示词出内容"，且要挂流式。

## 015.模型由调用方直传（框架不推理）

**铁律**：`model` 由**调用方必传**，框架**不挑默认、不校验归属、不按能力猜**。

| 口径 | 说明 |
|------|------|
| `model` 必传 | 空 → 400（沿用现有 `requireModel` 语义） |
| 不挑默认 | 绝不从 provider 的 `models` 清单里选"默认模型" |
| 不校验归属 | 不判断 `model` 是否在该 provider 的 `models` 清单内 |
| 不按能力猜 | 不因"这是 image"去推断模型——`model` 永远由调用方给 |

> provider 的 `models` 字段（逗号分隔清单）**仅用于管理面展示 / 导出，不参与任何解析**。

## 016.能力归属：代码承载，不进管理面

**AI 管理面只管两件事：provider + api key**——一个 api key 可对应多个模型，**模型与能力的映射不在管理面建模**（管理到不了那个粒度）。

因此**能力不落表、不声明**：

- "这家支持 inference / image / tts / asr" 由**能力端口实现**（`AiInferencePort` / `AiImagePort` / `AiTtsPort` / `AiAsrPort` 的 `supports(providerCode)`）在**代码层**承载；
- 调用方给 `provider + model`，用例按能力找端口，**无实现 → 400**（现有行为）；
- "是否用了生图/生语音"**不看配置、看调用**——本地存储闸就挂在图片/语音用例上（见 §017）。

## 017.产物落盘与本地存储闸

- **落盘**：图片/语音产物（`AiMedia` 的 bytes/b64）经 `AiMediaStorePort` 写入存储中心（`StorageResolverPort`，**存储中心零改动**），返回 `storageKey` + 预签名 URL；
- **本地存储闸**：调用图片/语音**之前**检测本地实例（`provider=local011` 且启用）；
  - 检测不到 → **只记一条 WARN**（不刷屏）+ **拒绝服务**（该能力快速失败，**不关停整个应用**）；
  - 之后补上本地实例 → 检测通过即自动恢复；
- 推理（文本）**不落盘**，不受此闸约束。
- **生命周期不在本中心**：AI 中心只**产生并返回引用**（`storageKey` / 地址），**不管何时删**；存储中心只**存取**，不做 TTL / 生命周期。**文件何时删由使用方决定**（用完即删或留存）——这不是 AI 的能力，也不是存储中心的能力。

## 018.开放形态：HTTP + Service + 流式

| 形态 | 说明 |
|------|------|
| **HTTP** | 各模块控制器（`/klsjnh/aicenter/...`），对外 REST |
| **Service** | 应用层稳定接口（如 `AiInferenceUseCase`），**AI 开发**直接注入调用，不走 HTTP |
| **流式** | 推理支持 **SSE**（`text/event-stream`）与 chunked HTTP 流式返回 |

## 019.边界（不做 · 否定清单）

- 框架**不做**模型路由/负载均衡/自动选型（`model` 直传）；
- 不做计费/配额/限流（后续）；
- 不做向量库 / RAG / Agent 编排；
- 语音识别（ASR）本期**新增但先留骨架**（见 §020）；
- 密钥加密二期（与存储/消息同口径，当前明文入库）。
