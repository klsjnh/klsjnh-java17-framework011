## 011.运行视图（一次推理请求的完整链路）

```
Client ──JWT──► GlobalAuthFilter ──► AiInferenceController (web.aicenter, SSE)
                                        │
                                        ▼
                               AiInferenceUseCase (application.aicenter)
                                │            │
                    AiProviderResolver   AiCapabilityRegistry
                    （provider/api 解析）  （capability code → 适配器）
                                │            │
                                ▼            ▼
                      管理面配置(july_ai_model_provider)
                                             │
                                             ▼
                              OpenAiCompatInferenceAdapter (infrastructure.aicenter.provider)
                                             │  HttpUtil011（JDK HttpClient）
                                             ▼
                                        AI 厂商（SSE 上游）
                                             │
                                    chunk 逐段回传 SSE ◄── 客户端
```

## 013.三条内部链路

| 链路 | 路径 | 落点 |
|------|------|------|
| **推理（流式）** | Controller → UseCase → Resolver → Registry → `AiCapabilityPort` → 厂商 | 纯文本回传，不落盘 |
| **产物落盘** | TTS / 图片 UseCase → `AiMediaStorePort`（AiMediaStore011）→ `StorageResolverPort` → `ObjectStoragePort` | 调用必传存储实例 + 桶，媒体对象写存储中心 |
| **管理面 CRUD** | Controller → UseCase → 基座家族 RepositoryImpl → PO/Mapper | `july_ai_model_provider(+_api)`、`july_ai_domain(+_prompt)` |

## 015.关键设计件

| 件 | 位置 | 职责 |
|----|------|------|
| `AiCapabilityRegistry` | application 根 | 按 capability code 收编 `List<AiCapabilityPort>`（List 注入，空 = 能力未启用） |
| `AiProviderResolver` | application 根 | 解析调用方的 provider → api key（出参脱敏） |
| `AiModelProbe011` | infrastructure.modelprovider | provider / api key 级连通性探测 |
| `PromptRender011` | infrastructure.prompt | 提示词模板 render（主子表参数） |
| `AiMediaStore011` | infrastructure.media | 产物落盘统一口（解析 locator → 存储中心写对象） |
| 厂商适配器 ×6 | infrastructure.provider | openai 兼容 ×4（inference / tts / asr / image）+ agnes / sensenova 图片 |

## 021.与框架其他部分的关系

| 关系 | 方向 | 说明 |
|------|------|------|
| 存储中心 | 本 starter → core 端口 | 产物落盘；不引 `center-storage011-starter` 时落盘类调用失败，管理面不受影响 |
| IAM | 本 starter → core 端口 | 审计（UserAuditPort）；鉴权由 security-starter 统一承担 |
| 平台导出 | 本 starter → core SPI | `AiModelProviderExportProvider` 注册进导出注册表 |
| Swagger | core 固定 URL 组 | `aicenter` 组随 starter 在场展示 |

## 024.线程与超时

- 推理 SSE：Controller 侧独立异步回传（超时 `krt.ai-center.chat-timeout-seconds`）；客户端断连时关闭上游 HTTP 流（try-with-resources）。
- 厂商 HTTP：`HttpUtil011`（JDK HttpClient），无连接池魔改；密钥只从管理面读、出参脱敏、日志不落 key。
