## 011.命题

**AI 中心 = 一个 starter。** `center-ai011-starter` 自包含 AI 中心的全部代码：管理面（模型接入主子表、提示词业务域）与能力引擎（推理 / 图片 / 语音适配器、媒体落盘）。消费方**引 starter 得到全部，不引则整个中心不存在**——无半初始化、无残留端点、无需导入 AI 表。

## 013.与 core 的边界（剥离后）

| 归属 | 内容 |
|------|------|
| **本 starter** | `com.klsjnh.domain.aicenter`（聚合 / 端口 / SPI）、`application.aicenter`（用例 / 注册表 / Resolver）、`infrastructure.aicenter`（PO/Mapper/RepositoryImpl + 探针 + PromptRender + 媒体落盘 + 厂商适配器）、`web.aicenter`（5 Controller + Converter + VO） |
| **core011（被本 starter 依赖）** | `common`（HttpUtil011 / FrameConst011 / Operator011）、`domain.shared`（EntityId / AuditInfo）、`domain.iam.user.UserAuditPort`（审计出口）、`domain.storagecenter.object`（产物落盘**端口**；仓储随 center-storage011-starter）、`platform011.export`（ExportProvider SPI 注册口） |
| **不再存在于 core** | 任何 `aicenter` 代码 —— core 对 AI **零残留** |

> 命名口径：中心类 starter 无 `java17-` 前缀，`center-<名>011-starter`。

## 016.依赖关系

```
center-ai011-starter ──► center-storage011-starter ──► java17-core011 ──► java17-security-api011
（ai 必依赖 storage：媒体落盘经其仓储与 `@EnableStorage011Center` 元注解；仍无下游，无人依赖本 starter）
```

对 core 的消费点（全部经 core 依赖获取，无环）：

| 消费点 | 用途 |
|--------|------|
| `StorageResolverPort` / `ObjectStoragePort` / 仓储 | 媒体产物落盘（调用必传实例 + 桶） |
| `UserAuditPort` | 用户审计落地 |
| `ExportProvider` 注册 | 模型接入随平台导出 |
| `HttpUtil011` 系列 | 厂商 HTTP 通道（纯 JDK HttpClient 封装） |

## 019.装配机制

- starter 代码在 `com.klsjnh.{infrastructure,application,web}.aicenter` 包树下，由本中心 `AiCenterAutoConfiguration011`（随 `@EnableAi011Center`）扫描——**加注解才装配**；jar 在而注解不在，零注册。
- 宿主**不扫描任何框架包**；本中心装配由 `AiCenterAutoConfiguration011` 承载（注解式，不走 `AutoConfiguration.imports`）。

## 099.怎么接入（注解式）

> **本中心默认关**：jar 在 classpath 上不会自动生效 —— 必须由业务项目**显式开启**（bean 与 mapper 都随注解注册）。

- **依赖**：`center-ai011-starter`
- **access 可选**：权限种子由 `AiPermCatalogSeedConfig011` 用 `@ConditionalOnClass(name="…JulyPermObjectRepository")`（**字符串形式**）挂条件；不装 `center-access011-starter` 时整段跳过（启动前提见 020 §4：须 permissive 回退或 access 在场）
- **开启**：启动类加 `@EnableAi011Center（已隐含 @EnableStorage011Center）`
- **不开启**：本中心的 HTTP 全部 404、bean 与 mapper 都不注册（详见 [013 模块清单与怎么用](../013.topic-project-structure.md) §025）
- **注解式而非配置开关**：开关写在代码里（一眼看出装了哪些中心），且"默认关"才是真隔离
