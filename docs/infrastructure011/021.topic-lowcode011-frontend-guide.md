## 011.接入基线（所有模块通用）

| 项 | 约定 |
|----|------|
| Base | `/klsjnh`（低代码：`/klsjnh/lowcode011`；存储中心：`/klsjnh/storagecenter`） |
| 鉴权 | 管理端 `Authorization: Bearer <jwt>`（登录 `POST /klsjnh/system011/julyUser/v1/loginByUserName`） |
| 统一信封 | `{ statusCode, message, errorMessage, timestamp, traceId, data }`；`200` 成功，错误看 `statusCode` + `errorMessage` |
| 分页 | 入参 `pageIndex`(1 起) / `pageSize`；出参 `PageResult011{ pageIndex, pageSize, total, totalPages, rows }` |
| 时间 | `LocalDateTime` 序列化为 ISO（如 `2026-09-17T18:27:42`，带 `T`）；前端做展示格式化 |
| **URL 规约** | **禁 path variable**：`objectName` 一律走 **query 或 JSON body**（例：`/load?objectName=...`） |
| 命名 | 域全小写 011（`lowcode011` / `storagecenter`）、模块小驼峰 + `/v1` |

### 13.4 模板（040 / 050 多格式）
| 端点 | 方法 | 说明 |
|------|------|------|
| `/getTemplate011` | GET | 默认骨架（`?format=json\|csv\|md\|xlsx?`；json 回信封，其它回文件流） |

## 015.MetaDTO 形状（1 主 3 子）

```json
{
  "metaData":   { "objectName":"bpm_user011", "objectType":"type011", "description":"...", "businessField":"sid",
                  "packageName":"...", "routerPath":"...", "remark":"...", "sortOrder":9999,
                  "publishStatus":"draft", "version":"" },
  "fieldData":  [ { "code":"sid","name":"业务ID","fieldType":"string","length":33,"notNull":true,"defaultValue":null,"sort":1 } ],
  "displayData":[ { "code":"sid","name":"业务ID","align":"left","width":140,"componentType":"input","displayType":"all","param011":null,"sort":1 } ],
  "serviceData":[ { "code":"query","name":"查询","description":"","objectType":"type011","paramType":"query","serviceContent":"","enabled":true,"sort":1 } ]
}
```

**枚举**（详见 `common/domain enums`）：
- `FieldType011`：`id/status/create_by/update_by/create_time/update_time/string/int/float/date/boolean/text`
- `ObjectType011`：`type011/type013/type_tree/type_tree011/type021`
- `DisplayType011`：列表/表单等场景（`all` 等）

## 017.开放 API（外部 / 无 JWT 场景）

- 前缀 `/klsjnh/open/v1`，鉴权头 **`X-Api-Key`**（JWT 白名单，无需登录）。
- 端点：`GET /meta?objectName=`、`POST /query`（`{objectName,filters,pageIndex,pageSize}`）、`POST /insert|update|delete`（body 带 `objectName`）。
- 仅**已发布**对象可用；`allowedOps` 决定可用操作；错误 key → 401。

## 021.前端注意事项（血泪清单）

1. **objectName 走 query/body**，不要拼到路径里（后端门禁禁止 path variable）。
2. **模板的 `fieldData` 含平台基列**（`id/status/dr/create_by/update_by/create_time/update_time`）——回填/上传时**保留它们**，别删；也**别再新增同名**（含大小写）字段，否则审核报 `duplicate field code`。
3. **`businessField` = 业务唯一键**（如 `sid`），固定 `VARCHAR(33)`；`pk_*` 外键列也固定 `VARCHAR(33)`。
4. **数据同步按列名匹配**：源列名要与目标列一致，或 SQL 里用别名（`orgid pk_organization`）。
5. **`status` 语义合并（B 口径）**：若把业务状态映射到平台 `status`，前端 admin 启停与同步会互相覆盖，展示时要明确。
6. 分页参数是 `pageIndex/pageSize`（不是 `pageNum`）；时间是 ISO 串。
7. 发布时间可能返回 `ddl=null`（无新增列）；`previewDdl` 是**全量 CREATE**，与 `publish` 的 ALTER 语义不同，仅作预览。
8. 上传模板：`multipart` 用 part 名 `file`；也可直接 `application/json`。
9. 开放 API 的管理端配置可回明文 apiKey **仅一次**，前端要提示用户立即保存。

## 023.建议的页面与交互

- **模型列表**：`listModels` + `selectListByPage`（状态标签 draft/published）。
- **设计器**：三 Tab（字段/展示/服务）+ 探测（走 `dataservice011` 的 `probe`）+ `previewDdl` 按钮 + 保存（`save`）。
- **发布/数据**：`publish` 按钮 + `importDataFromSql` 分页进度（用 `hasMore/nextPageNum` 循环）。
- **模板**：导出下载（`downloadTemplate011`）、导入（`uploadTemplate011` 显示校验报告 + `previewDdl`）、部署（`deployObject`）。
- **开放 API**：开关 + 鉴权模式 + 操作勾选 + 生成/轮换 key（明文只显示一次）。
