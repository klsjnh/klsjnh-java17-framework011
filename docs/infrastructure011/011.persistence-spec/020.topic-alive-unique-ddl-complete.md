## 011.规约（定案）

1. **红线**：带业务唯一键的表，唯一索引**只约束存活行**（`dr='0'`）。手段 = 生成列 `alive_*`（`dr='0'` 时 = 业务键，否则 `NULL`）+ `UNIQUE(alive_*)`。
2. **双轨**：
   - **CREATE 真源**：各 `docs/sql/july_*.sql` 新建表直接写 `alive_*` + `UNIQUE(alive_*)`（对齐 `july_demo011.sql`），不写裸 `UNIQUE(业务列)`。
   - **存量 ALTER**：`logic-delete-unique-fix.sql` 覆盖全部目标表（清单见 §013）。
3. **默认值**：`sort_order` 模板默认 `9999`；字典等主题业务定案为 `0` 的，保持该主题 CREATE 默认。
4. **不做**：不物理删墓碑；不改业务列；不写 Java 双写；不碰无业务唯一键的表；运行期自动 migration、非 MySQL 生成列语法、字段级变更审计（另案）。
