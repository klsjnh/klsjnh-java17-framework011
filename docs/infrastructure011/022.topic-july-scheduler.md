## 011.命题

**调度 = 一个可选 starter。** `java17-scheduler-quartz011-starter` 自包含 julyScheduler 完整能力：管理面 CRUD + start/stop/runOnce、领域聚合、持久化、Quartz 引擎（RAMJobStore）、`JobHandler` SPI 注册与启动重注册、**执行审计主子表**。

消费方**引 starter 得到全部；不引则 classpath 无调度管理面与 start 能力**（端点 404，非仅 `@ConditionalOnClass` 开关）。

## 012.主子表与审计分流

| 表 / 通道 | 记什么 | 不记什么 |
|-----------|--------|----------|
| **主** `july_scheduler` | 任务定义（code/cron/handler/运行态/`execute_times`） | — |
| **子** `july_scheduler_audit` | **实际跑完**的 job 结果（cron 触发或「执行一次」）→ `SUCCESS`/`FAIL` + `error_message` | 启停、未触发的 update |
| **`july_user_audit`**（`@AuditLog`） | 操作者管理动作：insert/update/delete/**start/stop/runOnce（谁点的）** | job 成败细节 |
| **平台审计**（config/dict/backup/export/import） | 平台域专用 | **调度一律不入** |

查询子表：`POST /klsjnh/system011/julyScheduler/v1/selectExecListByPage`（Body：`pkMt` + 分页；权限码 `system011:julyScheduler:select`）。

## 013.与 core / access 的边界

| 归属 | 内容 |
|------|------|
| **本 starter** | `domain/application/infrastructure/web` 下 `system011.scheduler` 全栈；`JobHandler` / `SchedulerPort` SPI；Quartz `SchedulerEngine` / `SchedulerHandlerJob` / `JobHandlerRegistry` / `SchedulerBootstrap`；`july_scheduler_audit` 写读 |
| **core011（被本 starter 依赖）** | `common`（信封 / `Status011` / 异常）、`domain.shared`（EntityId / AuditInfo）、鉴权端口契约（`AuthorizationPort` 等）；`july_user_audit` 写路径（`@AuditLog`） |
| **不再存在于 core** | 任何 julyScheduler 管理面 / 引擎代码 —— core 对调度 **零残留** |
| **center-access011-starter** | 权限目录播种 `JulySchedulerPermCatalogSeed011`（`@ConditionalOnClass(JulySchedulerPermissionCodes011)`）：**仅当本 starter + access 同时在场**才写入 `julyScheduler` 对象/动作码；无 access 时 debug 下 `assertHas` 放行，生产写白名单依赖 access |

> 装配：starter 类落在 `com.klsjnh.{application,web,infrastructure}`，由 core 的 `CoreAutoConfiguration011` `@ComponentScan` 扫入；宿主**无需**扫描框架包。

## 017.消费方怎么用

1. BOM import + 依赖 `java17-scheduler-quartz011-starter`（及必选 security / data）。
2. 建表：执行 [july_scheduler011.sql](../sql/july_scheduler011.sql)（含 `july_scheduler_audit`）。
3. 实现 `JobHandler`（`handlerName` + `execute`）并注册为 Spring Bean。
4. 调管理面 `insert`（默认停止）→ `start`；或 `runOnce` 立即触发；用 `selectExecListByPage` 查执行结果。
5. 活示例：仓库外兄弟工程 **`java17-demo013-app013`**（`Demo013Job` / handler `demo013job`，端口 11163）。

参考应用 `java17-app011` 内另有 `com.klsjnh.scheduler.Demo011Scheduler`（框架内 30s tick 演示），与消费方 demo 无关。
