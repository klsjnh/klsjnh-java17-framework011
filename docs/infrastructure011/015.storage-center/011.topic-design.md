## 011.命题

**存储中心 = 一个 starter + 一份留在 core 的端口契约。** 与 security-api 同构：端口是框架 API（core），实现是技术适配（starter）。消费方引 starter 得到完整管理面（provider 实例 / 桶 / 对象 / 在线编辑）与 local011 + minio011 双适配器；不引则中心整体不存在，而 core 自身（含备份用例的软依赖）照常工作。

## 013.与 core 的边界（剥离后）

| 归属 | 内容 |
|------|------|
| **本 starter** | `domain.storagecenter.storage`（JulyStorageProvider / Bucket 聚合 + 仓储 + EditableTextPolicy）、`application.storagecenter`（Provider / Bucket / Object 用例 + 在线编辑）、`infrastructure.storagecenter`（Registry / Defaults / Properties / Resolver + entity/mapper/repository/seed + 适配器）、`web.storagecenter`（2 Controller + Converter + VO） |
| **core011 保留（端口契约）** | `domain.storagecenter.object`：`ObjectStoragePort` / `ObjectStorageProviderFactory` SPI / `StorageResolverPort` / `StorageDefaultsPort` / `StorageConnectionConfig` / `StorageProbe` / 对象列表模型 / `StorageProviderCodes011` |
| **core011 消费端口的一方** | `platform011.backup.BackupUseCase`（软依赖：`ObjectProvider`，存储缺席时备份返回 403 提示，应用照常启动） |

> 命名口径：中心类 starter 无 `java17-` 前缀，`center-<名>011-starter`。

## 016.依赖关系

```
center-ai011-starter ──┐
                       ├──► center-storage011-starter ──► java17-core011 ──► java17-security-api011
java17-observability011-starter ──┤（optional，健康指示器条件化）        ▲
                       │                              端口契约（object）留在 core
java17-app011 ─────────┘
```

| 消费方 | 依赖 | 说明 |
|--------|------|------|
| `center-ai011-starter` | **必依赖** | AI 媒体落盘解析存储实例（引 AI 自动带存储） |
| `java17-observability011-starter` | optional | 存储健康指示器条件化（类不在则不注册） |
| `platform011.backup`（core） | 软依赖 | `ObjectProvider`，备份时缺席 → 403 明确提示 |

## 019.装配机制

- starter 代码在 `com.klsjnh.*.storagecenter` 包树下，由 core 的 `CoreAutoConfiguration011` 定向扫描随 classpath 收编。
- `ObjectStorageProviderRegistry` 以 `List<ObjectStorageProviderFactory>` 收编适配器工厂——local011 / minio011 内置，厂商（如 s3011）实现 SPI 即插。
- provider 选择是**运行时配置**：`krt.storage-center.default-type: local011 | minio011`，两适配器随 starter 同场提供。

## 022.能力与端点

| Controller | URL 前缀 | 说明 |
|------------|----------|------|
| `JulyStorageProviderController` | `/klsjnh/storagecenter/julyStorage/v1` | provider 实例 + 桶管理（主子表） |
| `JulyObjectController` | `/klsjnh/storagecenter/julyObject/v1` | 对象上传 / 下载（流式）/ 在线编辑 readText·saveText / 预签名 |

## 025.配置键（StorageProperties，随本 starter）

| 键 | 说明 |
|----|------|
| `krt.storage-center.default-type` | `local011` / `minio011`（运行时选择） |
| `krt.storage-center.local011.base-path` / `default-bucket` | 本地盘根与默认桶 |
| `krt.storage-center.minio011.endpoint` / `access-key` / `secret-key` / `default-bucket` | MinIO 连接与默认桶 |
