# 013 — center-storage011-starter · 系统整体架构

> 四篇一套：[011 设计思路](011.topic-design.md) · 本篇架构 · [015 怎么使用](015.topic-usage.md) · [016 二开手册](016.topic-secondary-dev.md)。

## 011.运行视图（一次对象写入）

```
Client ──JWT──► GlobalAuthFilter ──► JulyObjectController (web.storagecenter)
                                        │
                                        ▼
                              StorageObjectUseCase (application.storagecenter)
                                        │
                              StorageResolver011 (infrastructure, 端口实现)
                               │  按 provider 行 + default-type 解析
                               ▼
                    ObjectStorageProviderRegistry ──► LocalObjectStorageAdapter (local011)
                                                    └─► MinioObjectStorageAdapter (minio011)
                               │
                               ▼
                    本地盘 ./storage011/<bucket>/...   或   MinIO (S3 协议)
```

## 013.三层职责切分（剥离后的关键）

| 层 | 位置 | 内容 |
|----|------|------|
| **端口契约** | core `domain.storagecenter.object` | `ObjectStoragePort`（读 / 写 / 列举 / 预签名 / 编辑）、`ObjectStorageProviderFactory` SPI、Resolver / Defaults 端口、连接配置与列表模型 |
| **解析与默认值** | 本 starter `infrastructure.object` | `StorageResolver011`（表驱动实例 → 适配器，带缓存）、`StorageDefaults011`（配置默认桶）、`ObjectStorageProviderRegistry`（工厂收编） |
| **适配器** | 本 starter `infrastructure.object.adapter/provider` | local011（文件系统路径校验：拒绝 `..`，规范基路径）· minio011（S3 协议，预签名） |

## 015.两条管理面链路

| 链路 | 路径 |
|------|------|
| **实例 / 桶管理** | JulyStorageProviderController → Provider/Bucket UseCase → 主子表 RepositoryImpl（`july_storage_provider` + `_bucket`）→ 测试连接走 `DataSourceProbe011` 同型的存储探针 |
| **对象 / 在线编辑** | JulyObjectController → StorageObjectUseCase → Resolver → 适配器；编辑走 `EditableTextPolicy`（1MB 上限） |

## 018.跨中心消费（端口契约的价值）

| 消费方 | 用的端口 | 缺席语义 |
|--------|----------|----------|
| `platform011.backup`（core） | `StorageResolverPort` + `StorageDefaultsPort` + `ObjectStoragePort` | `ObjectProvider` 软依赖 → 备份调用返回 403"存储能力未启用" |
| `center-ai011-starter`（媒体落盘） | 同上 + 管理面仓储（解析实例） | AI starter 传递依赖本 starter，不会缺席 |
| `java17-observability011-starter`（健康指示器） | `JulyStorageProviderRepository` | optional 依赖 + `@ConditionalOnClass` 自动装配，缺席不注册 |

## 021.安全要点

- 本地适配器：key 拒绝 `..`，bucket 拒绝 `..` 与路径分隔符（黑名单式校验，勿"优化"成 `resolve` 拼接）；
- `readText/saveText` 有 1MB 上限；`access_key` / `secret_key` 落库经 [033 SecretCipher](../033.topic-platform-security.md) 可逆加密（`enc:v1:`），出参打码 `******`；领域明文上限 accessKey≤100、secretKey≤300；库列 `VARCHAR(512)`；
- 敏感操作审计：`saveObjectText` 挂审计，`readObjectText` 暂不挂（017 已登记）。
