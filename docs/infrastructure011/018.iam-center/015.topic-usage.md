## 011.管理面（身份与导航）

1. 组织树 → 用户挂靠（可选）。
2. 菜单（目录/页面/按钮）→ 按钮 `permissionCode` 与目录一致（导航显隐）。
3. 角色 → `assignMenus`；用户 → `assignRoles`；内置角色 = 全权限。
4. 登录拿 token → `getUserMenuTree` 看导航。

权限目录登记、按对象授撤、用例挂码、启停闭环：**[016](016.topic-dynamic-permission.md)**。

## 013.后期：角色组（P4）

用户 ∈ 组 → 组含角色 → 有效码 = 直授 ∪ 组内；`assertHas` 调用点不变（语义仍见 [016](016.topic-dynamic-permission.md)）。
