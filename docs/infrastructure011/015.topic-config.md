# 015 — 配置体系（Configuration）

> 配置键的**事实来源**：新增 / 变更配置键必须先改本文档。
> 结构规则：`application.yml` **入库**（仅公共结构：port / 应用名 / 默认 profile，**不含密钥**）；`application-development.yml` **入库**（开发共享）；`application-local.yml`（本机私有覆盖）与 `application-production.yml`（生产部署）**不入库**。

## 011.文件分层

| 文件 | 入库 | 用途 |
|------|------|------|
| `application.yml` | ✅ | 公共结构：port / 应用名 / 默认 profile（`#active: local` / `#active: production` 注释切换 + `profiles.group.local`）；**不含任何密钥** |
| `application-development.yml` | ✅ | 开发共享：数据源 + `krt.status: debug` + dev JWT secret |
| `application-local.yml` | ❌（已忽略） | 本机私有覆盖：只写本机差异，未声明的键继承 development（经 `profiles.group.local` 叠加） |
| `application-production.yml` | ❌（已忽略） | 生产部署：数据源 + `krt.status: production` + 真实 secret |

`.gitignore` 已挡 `application-*.yml / application-*.yaml`，并放行 `!application-development.yml`（不影响 `application.yml` 本身）。

> 说明：`application-local.yml` / `application-production.yml` 在当前工作副本中已存在（本地自建、未入库）；fresh clone 需按 §016 模板自建 local / production。

## 013.公共键（server / spring）

| 键 | 值 | 说明 |
|----|----|------|
| `server.port` | 11610 | 服务端口 |
| `spring.application.name` | java17-app011 | 应用名 |
| `spring.profiles.active` | development | 环境：development / production（生产部署时切换） |

## 015.框架键（krt.* → 绑定类 KrtConfig011）

| 键 | 默认 | 说明 |
|----|------|------|
| `krt.status` | `application-development.yml` 显式 `debug`；**代码缺省 PRODUCTION**（键完全缺失时） | 运行态三态，见 `FrameworkStatus011` |

三态语义：

| 值 | 鉴权行为 |
|----|----------|
| debug | 不拒绝，全放行；带 `${Authorization: Bearer}` 时仍尽力解析并记录操作人 |
| development | 强制验 token；免密登录（loginByUserName）可用 |
| production | 强制验 token；免密登录被拒；登录强制 bcrypt + 账号启用校验 |

登录失败、账号禁用、缺失/无效/过期 token 统一返回 401。

**生产卫兵**：`krt.status=debug` + production profile → 启动直接失败（忘改配置的代价是起不来，不是裸奔）。

## 016.本机覆盖模板（`application-local.yml`，不入库）

`application-development.yml` 已是入库的开发共享基线（数据源 + `krt.status: debug` + dev secret）。需要本机差异化时，新建 `application-local.yml` 只写差异，并在 `application.yml` 打开 `#active: local`（`profiles.group.local` 会把 local 叠加在 development 之上）：

```yaml
# application-local.yml —— 本机私有覆盖，未声明的键继承 development
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/your_db?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: <你的账号>
    password: <你的密码>
```

> 数据源依赖已接入（druid-spring-boot-3-starter）：主库与动态数据源池均为 Druid。

## 017.生产部署要点

1. `SPRING_PROFILES_ACTIVE=production`；
2. `krt.status=production`（production yml 或环境变量 `KRT_STATUS`）——启动卫兵强制；
3. 数据源用环境变量注入（`SPRING_DATASOURCE_URL` 等），不落盘。
