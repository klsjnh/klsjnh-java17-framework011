## 011.领域模型

```text
july_organization（树）
        ▲ pk_org
july_user ──< july_user_role >── july_role ──┬──< july_role_permissions >── permission_code
             │                                │         ▲        ▲
             │                                │    来自菜单按钮   来自目录直授
             │                                │
july_user_audit                               │
                                              │
权限目录（详 [016]）                            │
  july_perm_object / july_perm_action
       │
       └── 菜单按钮 permission_code 宜 ∈ 目录

后期 P4：
  july_role_group ── 有效码 = Σ(直授 ∪ 组内)；内置角色全量旁路
```

- **权限码格式**：`模块:对象:动作`（如 `system011:julyScheduler:start`）。
- **内置角色**（`is_builtin='1'`）：删/停保护；菜单树与 `AuthorizationPort` 全量旁路。

## 013.主子聚合与仓库

```text
聚合① july_user（core · BaseMasterSubRepository；user_role 级联归 access）
  └── july_user_audit    append-only，不入级联
聚合② july_role（access · BaseMasterSubRepository）
  └── july_role_permissions  toggle（菜单通道 + 直授通道）
独立 july_menu / july_organization（access · BaseTreeRepository）
独立 july_perm_object / july_perm_action（access · BaseRepository 族）
july_user_role（access · 用户-角色结）
```
