## 017.任务 B — 存档（P3 暂缓 · 先别做）

> **触发条件**：出现第一个调用 `BaseMasterSubRepository.getWithChildren`（Map 版）的生产路径，或用户明示开工。

### 011.若开工时的定案

1. **可见性：方案 (b)** —— 新增 opt-in 接口（建议名 `ChildKeyed`，放 `persistence.entity` 或 `persistence.support`）：

```java
public interface ChildKeyed {
    /** Stable map key for getWithChildren; lowercase plural domain noun. */
    String childMapKey();
}
```

2. `MasterSubSupport.childKey(repo)`：`repo instanceof ChildKeyed k ? k.childMapKey() :` 现算法回落。  
3. **禁止**在 `BaseRepository` 上加 `protected`/`public` `childMapKey()`（跨包 `protected` 无效；且污染通用基类）。  
4. **不做 B2**（除非用户另批）：零 Map 消费者时上强类型 = 空转；域层已有 `JulyAiDomainBundle` 等先例，真要强类型应在**有调用方**时按域 Bundle 走，不必先造通用 `MasterSubBundle`。  
5. 若做 B1 覆写，键名约定：**小写复数名词、域内语义**：

| 子仓（注册进 getChildServices 的） | 建议 key |
|------------------------------------|----------|
| `JulyDictionaryItemRepositoryImpl` | `items` |
| `JulyAiDomainPromptRepositoryImpl` | `prompts` |
| `AiModelProviderApiRepositoryImpl` | `apis` |
| `JulyStorageProviderBucketRepositoryImpl` | `buckets` |
| `JulySyncRuleColumnRepositoryImpl` | `columns` |
| `JulyUserRoleRepositoryImpl` | `userRoles` |

（执行前再 `rg getChildServices` 核对清单。）

## 018.任务 C — 已开张（限定域 · 2026-09-22 用户批准）

**按原则把「主+子整存」铺到适用域**（不再是无条件撤）：

- **已落地（真 Replace）**：模型接入（provider + api）· 同步规则（rule + column）——`saveWhole`（主 insert\|update + 子先逻辑删旧再插新）+ `getWithChildren`；
- **只读侧**：存储提供方 —— 仅 `getWithChildren`；桶 = **物理资源** → **Incremental**，不做整存；
- **不适用**：字典（[027](../../requirement013/027.topic-dictionary.md) 禁 Replace）· 用户 / 角色（toggle-dr，非级联子表）；
