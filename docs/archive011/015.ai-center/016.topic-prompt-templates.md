## 011.命题

提示词管理开建，采用**主子表**。**主 = 业务域树**（可分层、可排序），**子 = 提示词**。**提示词编码 `prompt_code` 全局唯一**（不按域隔离，便于跨域引用与检索）；**业务域编码 `domain_code` 全局唯一**。

## 013.结构（主子表）

**主表 `july_ai_domain`（业务域树）**

| 列 | 说明 |
|----|------|
| `domain_code` | 域编码，**全局唯一**、不可变 |
| `domain_name` | 域名称 |
| `parent_id` | 上级域 id（**空串为根**） |
| `sort_order` | 排序（越小越靠前） |
| `status` / 审计 / `dr` | |

**子表 `july_ai_domain_prompt`（提示词）**

| 列 | 说明 |
|----|------|
| `pk_mt` | 主表链接（`july_ai_domain.id`） |
| `prompt_code` | 提示词编码，**全局唯一**、不可变 |
| `prompt_name` | 名称 |
| `scene` | 适用能力（`inference` / `image` / `tts`，开放字符串，**仅分类**） |
| `content_mode` / `content` / `storage_*` | 正文（见 §017） |
| `variables` | 变量声明（可空） |
| `sort_order` / `status` / 审计 / `dr` | |

- **唯一键**：主 `domain_code` 全局唯一；子 `prompt_code` 全局唯一；
- **树**：`parent_id` 空串为根，平台按 `sort_order` / `id` 组装嵌套树；
- **渲染**：`${var}` 替换（不引模板引擎），**只按提示词编码解析**（编码全局唯一）；
- **与 provider 解耦**：模板**不绑定**模型 / provider（遵守"model 由调用方直传"）。

## 015.业务域：独立主表（树）

**业务域是独立实体**——主表 `july_ai_domain`，支持 `parent_id` 分层与 `sort_order` 排序（树）。域名称、域启停、域删除均纳入管理：

- **新增 / 修改**：`domain_code` 不可变；`parent_id` 非空时须指向存在的域，且不能指向自身；
- **删除**：仍有子域或仍有提示词时**拒绝删除**（先清子域 / 提示词）；
- **树查询**：`selectTree` 返回启用域的嵌套树（`children`）。

## 017.提示词类型：`inline` / `storage`（两种）

| 类型 | `content_mode` | 正文存哪 | 元数据 |
|------|----------------|----------|--------|
| **小（直接写）** | `inline` | 子表 `content` 列（`TEXT`，≈2.1 万汉字 / 64KB） | — |
| **大（落存储）** | `storage` | 对象存储（实例 + 桶 + key） | `storage_code` / `bucket` / `object_key` / `content_hash` / `content_size` |

子表 `july_ai_domain_prompt` 相关列：

```
content_mode  inline | storage（默认 inline）
content       正文（`TEXT`；inline 时用；storage 时留空）—— 64KB / ≈2.1 万汉字
storage_code  storage 时选：存储实例（下拉，来自存储中心；缺省=默认实例）
bucket        storage 时选：桶
object_key    平台生成的对象 key（如 prompt/<prompt_code>.md）
content_hash  内容 hash（变更检测 / 去重）
content_size  字节数
```

- **阈值**：`inline` 上限 **64KB（TEXT 上限）**，超过才 `storage`——3000–6000 字（≈9–18KB）一律 `inline`；
- **操作流程**：
  1. 新建/编辑先选 `content_mode`；
  2. `inline` → 文本框直接写；
  3. `storage` → 选**存储实例**（下拉：存储中心可用实例）→ 选**桶**（下拉：该实例的桶）→ 平台 `put`，DB 只存指针；正文**平台内编辑**或**上传文件**（`.md`/`.txt`/`.sql`）；读取时平台 `get` 回来渲染；
  4. **内容随元数据由平台管理**：改 → `put` 新对象（带 hash）→ 换指针 → 删旧；删元数据 → 删对象；
- **桶怎么选**：**B** 只选实例、桶用约定桶（`ai-prompt`，不存在则自建）。
