## 011.配置模型提供商与密钥

AI 管理面**只管两件事**：provider + api key。**模型不在这里管理**（一个 api key 可对应多个模型，调用时由调用方直传）。

```
POST /klsjnh/aicenter/julyAiModelProvider/v1/insert
{ "providerCode": "stepfun", "providerName": "阶跃星辰", "baseUrl": "https://api.stepfun.com/v1",
  "models": "step-3.7-flash,stepaudio-2.5-tts", "sortOrder": 10 }
→ IdVo011

POST /klsjnh/aicenter/julyAiModelProvider/v1/insertApi
{ "providerCode": "stepfun", "apiCode": "default", "apiName": "默认密钥", "apiKey": "sk-..." }
→ IdVo011
```

- `api_key` **出参不返回**（类型层剔除）；`updateApi` 留空 = 保持原值；
- `testConnection` / `testConnectionApi` 探活（HTTP 恒 200，结果在载荷）；
- 程序读入口（无 HTTP）：`getByCode` / `getApiList` / `getDefaultApi`。

## 013.推理：同步调用（HTTP + Service）

**HTTP**

```
POST /klsjnh/aicenter/julyAiInference/v1/chat
{ "provider": "stepfun", "model": "step-3.7-flash",
  "messages": [ { "role": "user", "content": "用一句话解释 DDD" } ],
  "temperature": 0.7, "maxTokens": 512 }
→ { "providerCode": "stepfun", "apiCode": "default", "model": "step-3.7-flash",
    "content": "...", "finishReason": "stop", "usage": {...} }
```

**Service（AI 开发，不走 HTTP）**：直接注入 `AiInferenceUseCase` 调用。

> **`model` 必传**：框架**不挑默认、不按能力猜**（见 [011 §015](011.topic-design.md)）。

## 015.推理：流式（SSE）

```
POST /klsjnh/aicenter/julyAiInference/v1/chat/stream
{ "provider": "stepfun", "model": "step-3.7-flash", "messages": [...] }
→ text/event-stream（逐片推送）
```

- 前端用 `EventSource` / `fetch` 流式读取；
- **帧格式 = OpenAI 兼容（标准）**：`data:{"choices":[{"delta":{"content":"..."},"finish_reason":null}]}`，末帧 `finish_reason` 非空（如 `stop`），最后 `data:[DONE]`；前端取 `choices[0].delta.content`（`\n` 在 JSON 内转义保留，**不要**按裸文本读）；
- domain 侧 `AiInferencePort.stream(...)` 返回分片流，web 层以 `SseEmitter` 输出。

## 016.图片：文生图 / 图生图 / 文图生图

统一入口：

```
POST /klsjnh/aicenter/julyAiImage/v1/generate
{ "provider": "stepfun", "model": "step-image-edit-2",
  "prompt": "一只戴帽子的猫", "size": "1024x1024",
  "storageCode": "default", "bucketCode": "ai-media" }
→ { "returnType": "url", "storageCode": "default", "bucket": "…",
    "storageKey": "ai/xxx.png", "url": "...", "mimeType": "image/png" }
```

**落盘定位（必传）**

| 字段 | 规则 |
|------|------|
| `storageCode` **或** `storageId` | 二选一必传（优先 code）；对齐 `july_storage_provider` |
| `bucketCode` **或** `bucketId` | 二选一必传（优先 code）；对齐 `july_storage_provider_bucket`；**不走默认桶** |
| 缺参 / 实例或桶不可用 | **400**（`storageCode or storageId is required` / `bucketCode or bucketId is required` / `… is not available`） |

三种模式（领域判据，厂商适配器各自映射）：

| 模式 | 入参 | 判据 |
|------|------|------|
| **文生图** | `prompt` | 无 `imageUrl` / `imageBase64` |
| **图生图** / **文图生图** | `prompt` + 输入图 | 有 `imageUrl` 或 `imageBase64`（`prompt` 作编辑/改写指令） |

- 产物经存储中心 **Port** 落盘，返回**定位三元组**（`storageCode` / `bucket` / `storageKey`=objectKey）+ URL；业务自记见 [存储中心 016](../infrastructure011/011.storage-center/016.topic-object-metadata-convention.md)；
- 密钥走 AI Provider 密钥表（`insertApi`），**勿把真实 key 写进仓库 / 文档 / 种子**。

### SenseNova（`providerCode=sensenova`）

配置示例（占位，密钥入库或环境变量，不落文档）：

```
providerCode: sensenova
baseUrl:      https://token.sensenova.cn/v1
model:        sensenova-u1.5-lite
```

| 模式 | 适配器路由 | SenseNova 字段要点 |
|------|------------|-------------------|
| 文生图 | `POST …/images/generations` | `model` · `prompt` · `size?` · `response_format`（`url` / `b64_json`）· `n=1` |
| 图生图 / 文图生图 | `POST …/images/edits` | 同上 + **`images:[{image_url}]`**（公网 URL 或 `data:image/...;base64,...`；**不支持无前缀纯 base64**）；未传 `size` 时默认 `auto` |

> SenseNova 官方把「参考图 + 指令」统归 edits；平台侧「图生图」与「文图生图」同一路径，差别只在 `prompt` 语义强弱。可选厂商字段（`watermark` / `prompt_extend` / `output_format`）首版不暴露，走厂商默认。
> 文档：[SenseNova 平台](https://platform.sensenova.cn/docs)。
## 017.语音：TTS / 语音识别

**TTS**

```
POST /klsjnh/aicenter/julyAiAudio/v1/synthesize
{ "provider": "stepfun", "model": "stepaudio-2.5-tts", "input": "你好，世界", "format": "mp3",
  "storageCode": "default", "bucketCode": "ai-media" }
→ { "storageCode": "default", "bucket": "…", "storageKey": "ai/xxx.mp3", "url": "...", "mimeType": "audio/mpeg" }
```

> TTS 与图片同一套落盘契约：`storageCode|storageId` + `bucketCode|bucketId` 必传；缺参 400。

**语音识别（ASR）**

```
POST /klsjnh/aicenter/julyAiAudio/v1/recognize
{ "provider": "stepfun", "model": "<asr-model>", "audioRef": "<storageKey | url | base64>" }
→ { "text": "识别出的文字" }
```

> ASR 产物是**文本**（不落盘，不必传存储）；输入音频可由使用方以 storage 引用 / URL / base64 提供。

## 018.扩展一个新厂商（能力适配器）

1. 实现对应**能力端口**（`AiInferencePort` / `AiImagePort` / `AiTtsPort` / `AiAsrPort`）：
   - `supports(providerCode)` 返回你的 provider code；
   - `invoke` 映射厂商字段；
2. `@Component` 注册（被 `AiCapabilityRegistry` 自动收集）；
3. 应用 `scanBasePackages` 含你的包；
4. 管理面插一行 provider + api key，调用时 `provider` 传你的 code。

> **能力不落表、不声明**：支持哪种能力由端口实现决定（见 [013 §019](013.topic-architecture.md)）。

## 019.产物交付与生命周期（使用方管理）

- AI 中心只**产生并返回定位**（`storageCode` / `bucket` / `storageKey`=objectKey / 地址），**不管何时删**；
- 存储中心只**存取**，不做 TTL / 生命周期；
- **业务自记指针**（可选）：见 [存储中心 016 对象元数据规约](../infrastructure011/011.storage-center/016.topic-object-metadata-convention.md)；
- **文件何时删由使用方决定**：
  - **即用即删**：如生图后交给飞书上传，**上传成功后**由编排方 `delete`；
  - **留存**：如要进相册，则保留不删。
- 参考：ASR 的输入音频，识别完即可由使用方删除。

> 这不是 AI 的能力，也不是存储中心的能力——**归使用方**。

## 020.落盘契约与限制

- **调用必传定位**：图片 `generate` / TTS `synthesize` 必须带 `storageCode|storageId` + `bucketCode|bucketId`；缺参 → **400**；**不**预绑配置、**不**默认桶、**不**强制 local011；
- 推理 / ASR **不传**存储；
- **大文件**：产物走 `byte[]`，注意大小上限（大文件流式列后续）；
- **密钥**：只在服务端使用，不落日志、不出参；加密二期；
- **超时/限流/费用**：首版超时 + 审计，限流/计费后续；
- **流式**：推理支持 SSE；图片/语音首版不做流式。

## 021.提示词管理（业务域树 + 提示词 CRUD + 渲染）

**主子表**：主 = 业务域树（`domain_code` 全局唯一），子 = 提示词（`prompt_code` 全局唯一）。

```
POST /klsjnh/aicenter/julyAiDomain/v1/insert
{ "domainCode": "report", "domainName": "报告", "parentId": "", "sortOrder": 1 }

POST /klsjnh/aicenter/julyAiDomain/v1/insertDetail
{ "pkMt": "<domain id>", "promptCode": "summary-report", "promptName": "报告摘要",
  "scene": "inference", "content": "请用一句话总结：${text}" }

POST /klsjnh/aicenter/julyAiDomain/v1/render
{ "promptCode": "summary-report", "params": { "text": "今天下雨" } }
→ { "data": "请用一句话总结：今天下雨" }
```

- `contentMode`：`inline`（`content` 直接落库，`TEXT` ≈2.1 万汉字）或 `storage`（超 64KB 落对象存储，选实例 + 约定桶 `ai-prompt`）；
- **`domain_code` / `prompt_code` 均全局唯一**；提示词归属一个业务域（`pk_mt`）；
- `render` 是**公共件**（AI 开发直接注入 `PromptRenderPort`，不走 HTTP），**只按提示词编码解析**；
- **一个模块** `julyAiDomain/v1`，**三种保存粒度**：主表（`insert` / `update`）· 主+子（`saveWhole` / `getWithChildren`）· 子表（`insertDetail` / `updateDetail`）（见 [016 提示词设计](016.topic-prompt-templates.md)）。
