## 015.迁移范围

**做（本期）**：`july_storage_provider` 主 + `july_storage_provider_bucket` 子 表驱动多实例 + 实例 CRUD/testConnection + 桶 CRUD + 对象 列表/分页/stat/上传/下载/删除/批删 + 在线编辑（readText/saveText）+ yaml 播种 + 适配器工厂（按实例配置造 adapter）。

**不做（边界外）**：预签名 URL 直传、分片上传/断点续传、桶生命周期/配额/策略、流式大文件（本项目端口为 `byte[]`，大文件见二期）、各厂商原生 SDK（cos011/tos011/oss011/s3011 仍分期）、前端页面。

## 017.业务规则

- `storageCode` 全表唯一、**不可变**；实例 `provider` 为**开放字符串**（内置 local011/minio011/s3011；其余由使用者实现 `ObjectStorageProviderFactory` 扩展，2026-09-19）；
- `local011` 必填 `basePath`；S3 系（minio011/s3011/cos011/tos011/oss011）必填 `endpoint` + `accessKey` + `secretKey`；
- **`accessKey` / `secretKey` 出参打码 `******`**（对齐老 f016 口径，2026-09-17 修订）；
- 停用实例（status=0）不可被解析，调用即 400；
- **在线编辑**：目标对象 ≤ **1MB**（`EditableTextPolicy.MAX_SIZE_BYTES`），UTF-8；编辑器类型按扩展名判定（`.sql`→sql 编辑器，其余→markdown）；
- 对象为**物理存在**（不落业务表）；实例与桶均落业务表并**逻辑删除**（桶为实例子表，`is_default` 标记默认桶）。

## 019.接口清单（前缀 /klsjnh/storagecenter）

**实例 `/storage`**：insert / update / logicDelete / logicDeleteBatch / getById(GET) / getByCode(GET) / selectListByPage / testConnection

**桶 `/bucket`**：selectList / selectListByPage / getBucket(GET，按 bucketCode) / insert(bucketCode+bucketName+isDefault+region) / remove(bucketCode) / testConnection

**对象 `/object`**：selectList / selectListByPage / stat(GET) / upload / download(GET) / remove / batchRemove / **readText(GET)** / **saveText**

## 021.边界外（本期不做）

- 流式 `InputStream` 端口形态（大文件，019 §021 二期已列）；
- 分片上传 / 断点续传 / 秒传；
- 桶生命周期 / 配额 / 策略 / 跨域；
- 厂商原生 SDK 适配器（分期）；
- 在线编辑的多用户协同 / 版本历史。
