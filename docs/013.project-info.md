# 013 — 项目信息（Project Info）

> 项目事实卡：定位 / 技术栈 / 骨架 / 构建与运行 / 当前能力。版本与键的事实来源是父 `pom.xml` 与 [015.topic-config](infrastructure011/015.topic-config.md)。

## 011.定位

`klsjnh-java17-framework011` —— Java 17 纯血 DDD 技术底座，Maven 多模块，供第三方业务系统 Maven 依赖引用。对外契约（响应信封 / 状态码 / 路由风格 / 公共表结构）稳定，见 [016.api-contract](../016.api-contract.md)。

## 017.构建与运行

```bash
./script011.sh gate      # 门禁：编码规范（正则 + AST）+ mvn 离线编译
./script011.sh           # gate → .vf 版本自增 → commit（ver 0.0.N）→ push
./script011.sh build011  # mvn clean package install
java -jar java17-app011/target/java17-app011-1.0.0.jar   # 11610 端口
```

- 端口 11610；接口文档 `http://127.0.0.1:11610/doc.html`（分组：系统管理011 / 存储中心）
- profile：development（默认，共享配置入库）/ production（部署机自建，不入库）；`krt.status` 见配置体系文档
- 环境依赖：Node 18+（门禁 AST：tree-sitter / tree-sitter-java，用户级 node_modules）· MySQL（docker 容器，宿主 33306）

## 019.当前能力（截至 2026-09-13）

- 持久化：BasePo 四件套 + 仓库基座五层家族（含 021 主子表）+ 审计自动填充（时间 + 操作人）
- IAM：用户（双登录 + roles）/ 角色（内置保护）/ 用户角色（toggle）/ 角色授权菜单 / 菜单树 + selectUserMenuTree / 用户审计（REQUIRES_NEW append-only + 分页查询）
- 调度：julyScheduler 全链路（Quartz 内存模式，JobHandler 注册器，重启自愈）
- 动态数据源：yaml ci011 懒加载 + SqlRoutingPort 读写 / 方言分页（clamp [10,500]）
- 存储中心：ObjectStoragePort（对象 + 桶 CRUD + stat）local011 / minio011 适配器，厂商分期
- 全局异常 → 统一信封（HTTP 与 statusCode 同步，errorMessage 仅 debug）
- 参考样板：`com.klsjnh.demo11` DDD 纵切面（第三方照抄入口）
