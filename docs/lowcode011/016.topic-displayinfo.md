# 023.topic-displayinfo（DisplayInfo011 · 展示列定义）

> 低代码知识库 · 值对象：`com.klsjnh.domain.lowcode011.model.DisplayInfo011`
> 总览：[011 metadata011 体系](011.topic-metadata011-system.md)；上级：[021 MetaData011](013.topic-metadata011.md)。

## 011.定位

`DisplayInfo011` 是 `MetaData011` 聚合内的**展示列定义**：列表/表单/自定义场景下「怎么显示一个字段」。它**绑定字段**（`displayCode` → `fieldCode`），决定前端表格/表单的列与组件。

## 013.组成

| 字段 | 说明 | 约束 |
|------|------|------|
| `displayCode` | 列编码（**身份，不可变**，绑定一个 `FieldInfo011.fieldCode`） | 必填，≤60 |
| `displayName` | 列名称 | 必填，≤60 |
| `align` | 对齐 | `left/center/right`，未知或空默认 `left` |
| `width` | 列宽（px） | 负数归一为 0 |
| `componentType` | 组件类型（前端渲染用，如 input/select/date…） | 必填，≤30 |
| `displayType` | 展示类型（`DisplayType011`） | null 默认 `all` |
| `param011` | 扩展参数 | 可空 |

## 015.展示类型（`DisplayType011`）

| 值 | 含义 |
|----|------|
| `all` | 全场景（默认） |
| `table` | 列表 |
| `form` | 表单 |
| `custom` | 自定义 |

## 017.不变式与工厂

- `create(displayCode, displayName, align, width, componentType, displayType, param011)`；`displayCode` 不可变。
- `updateBasics(displayName, align, width, componentType, displayType, param011)`。
- 访问器：`displayCode()/displayName()/align()/width()/componentType()/displayType()/param011()`。

## 019.在体系中的角色

- **绑字段**：`displayCode` 必须命中一个已存在的 `fieldCode`（038/040 校验：`display code not bound to a field`）。
- **前端渲染**：`componentType` + `displayType` + `align/width` 驱动列表列/表单控件。
- **同步数据里**：只影响展示，不产生物理列。

## 021.与 MetaDTO

`displayData` 段即 `displays`：`{ code, name, align, width, componentType, displayType, param011, sort }`。

## 023.字典字段的展示（配合 022 的 `dictionary011`/`dictionary013`）

- 当字段类型是 `dictionary011` / `dictionary013` 时，展示列 `componentType` 建议用 **`select` / `radio`**：
  - `dictionary011`：选项来自字段自身的 `param011`（`值|标签;...`）；
  - `dictionary013`：选项来自系统字典（前端调 `system011/julyDictionary/v1/selectItemListByType`）。
- `displayType` 决定出现场景（`table` 列表 / `form` 表单 / `all`）；列表里通常渲染**标签**（用字典把值翻成 label），表单里渲染**下拉/单选**。
- 展示列只影响呈现，**不产生物理列**；值域校验在字段层（`FieldInfo011` + `MetadataValueValidator`）。
