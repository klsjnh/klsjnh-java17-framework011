# 027.topic-designer（设计器 · listModels/load/save/previewDdl）

> 低代码知识库 · 设计器（039 一期）
> 总览：[011](011.topic-metadata011-system.md)；契约：[026 MetaDTO](019.topic-metadata-dto.md)；方案：[req013/039](../requirement013/039.topic-lowcode-designer-runtime.md)。

## 011.定位

设计器 = **建模 + 预览**：列出模型、载入 MetaDTO、保存（落一主三子）、预览建表 DDL。**零改库**（不发 DDL）。

## 013.端点（`/klsjnh/lowcode011/julyMetadata/v1`）

| 端点 | 方法 | 说明 |
|------|------|------|
| `/listModels` | GET | 模型列表（objectName/description/objectType/publishStatus/version） |
| `/load` | GET | `?objectName=` 载入 MetaDTO |
| `/save` | POST | MetaDTO 整包保存（insert/update by objectName） |
| `/previewDdl` | GET | `?objectName=` 预览 `CREATE TABLE`（与发布共用生成器） |

## 015.机制

- **save**：解析 MetaDTO → `JulyMetadataUseCase.insert/update`（三子整替）；`businessField` 归一 `string(33)`。
- **previewDdl**：读聚合 → `MetadataDdlGeneratorPort.generateCreate` → 返回 DDL 文本（**全量 CREATE**，即使表已存在）。
- **listModels**：主表分页（master-only）。

## 017.与发布/模板的关系

| 能力 | 设计器（本主题） | [028 发布](021.topic-publish-ddl.md) | [032 模板](025.topic-template.md) |
|------|------------------|--------------------------------------|-----------------------------------|
