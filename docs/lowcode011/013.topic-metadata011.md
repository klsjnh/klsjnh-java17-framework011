# 021.topic-metadata011（MetaData011 · 元数据主体）

> 低代码知识库 · 值对象形态：`com.klsjnh.domain.lowcode011.model.MetaData011`
> 总览：[011 metadata011 体系](011.topic-metadata011-system.md)；持久化形态见 [req013/038](../requirement013/038.topic-lowcode-core.md)。

## 011.定位

`MetaData011` 是低代码对象的**值对象聚合根**（`domain.lowcode011.model`），描述「一个业务对象长什么样」：对象属性 + 三个 owned 集合（字段 / 展示 / 服务）。它**不落库**，被 [033 业务建模](../requirement011/033.topic-business-modeling.md) 当作**交接产物**（`getModelData` 交 `metaData + fieldData`）。

> 与持久化聚合 `JulyMetadata`（038）**形态同源、职责不同**：`MetaData011` 是纯值对象；`JulyMetadata` 是持久化就绪聚合（带 `id`/`sortOrder`/审计）。039 的设计器/发布/模板走 `JulyMetadata`。

## 013.组成

| 字段 | 说明 | 约束 |
|------|------|------|
| `objectName` | 对象名（**身份，不可变**） | 必填，≤60 |
| `objectType` | 对象类型（`ObjectType011`） | 枚举 |
| `objectDescription` | 描述 | ≤300 |
| `businessField` | 业务字段映射 | — |
| `packageName` | 目标包名（代码生成预留） | — |
| `routerPath` | 路由 | — |
| `fields` | `List<FieldInfo011>` | owned |
| `displays` | `List<DisplayInfo011>` | owned |
| `services` | `List<ServiceInfo011>` | owned |

- **owned 集合无独立生命周期**：只能经聚合根增删改（`addField/removeField/updateField`、`addDisplay/…`、`addService/…`）。
- 三集合元素以其 `code` 在聚合内**唯一**。

## 015.不变式与工厂

- 私有构造：实例由 `create(...)` / `reconstitute(...)` 产出；对象名不可变，其他 basics 走 `updateBasics(objectType, description, businessField, packageName, routerPath)`。
- 校验：`objectName` 必填 ≤60；`objectDescription` ≤300；类型枚举由枚举自身收口。
- 访问器：`objectName()` / `objectType()` / `objectDescription()` / `businessField()` / `packageName()` / `routerPath()` + 三个集合访问器。

## 017.在 MetaDTO 中的映射

| MetaDTO 段 | 本聚合 |
|------------|--------|
| `metaData` | 对象的标量属性（objectName/objectType/description/businessField/packageName/routerPath） |
| `fieldData` | `fields`（FieldInfo011） |
| `displayData` | `displays`（DisplayInfo011） |
| `serviceData` | `services`（ServiceInfo011） |
