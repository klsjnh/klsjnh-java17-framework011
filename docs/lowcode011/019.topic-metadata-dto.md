# 026.topic-metadata-dto（MetaDTO · 对外形状与映射）

> 低代码知识库 · 契约形态
> 总览：[011](011.topic-metadata011-system.md)；聚合：[025 JulyMetadata](018.topic-july-metadata.md)；方案：[req013/038](../requirement013/038.topic-lowcode-core.md)。

## 011.定位

`MetaDTO` 是低代码对象的**对外 JSON 契约**（前端/AI/运行时都用它）：`metaData`（主）+ `fieldData` / `displayData` / `serviceData`（三子）。它**不落库**，由 `JulyMetadata` 聚合一主三子组装/反解。

## 013.形状

```json
{
  "metaData":   { objectName, objectType, description, businessField, packageName, routerPath, remark, sortOrder,
                  publishStatus, version, source? },
  "fieldData":  [ { code, name, fieldType, length, notNull, defaultValue, param011?, sort } ],
  "displayData":[ { code, name, align, width, componentType, displayType, param011, sort } ],
  "serviceData":[ { code, name, description, objectType, paramType, serviceContent, enabled, sort } ]
}
```
- 段 ↔ 表：`metaData`→`july_metadata`；`fieldData`→`_field`；`displayData`→`_display`；`serviceData`→`_service`。
- 模板扩展键：`templateVersion` / `_guide` / `metaData.source`（见 [032 模板](025.topic-template.md)）。

## 015.映射位置

| 方向 | 实现 |
|------|------|
| 聚合 → MetaDTO | `JulyMetadataDesignerUseCase.load` / `toMetaDto` |
| MetaDTO → 聚合 | `JulyMetadataDesignerUseCase.save`（设计器）/ `JulyMetadataTemplateUseCase.deployObject`（模板） |
| 快照 payload | `JulyMetadataPublishUseCase.toPayload`（写 `july_metadata_version.payload_json`） |

> 未单列 Converter，组装内聚在用例里（两处都从同一聚合读，字段保持一致）。

## 017.约定

- **含平台基列**：`fieldData` 里包含 `id/status/create_by/update_by/create_time/update_time/dr`（正常且必需）。
- 排序：各段按 `sort`（DB `sort_order`）。
- 时间：`publishStatus` / `version` 为字符串；时间字段 ISO（`T` 分隔）。
- 前端对接细节见 [infra011/021](../infrastructure011/021.topic-lowcode011-frontend-guide.md)。
