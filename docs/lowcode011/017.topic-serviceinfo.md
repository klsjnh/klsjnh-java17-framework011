# 024.topic-serviceinfo（ServiceInfo011 · 服务定义）

> 低代码知识库 · 值对象：`com.klsjnh.domain.lowcode011.model.ServiceInfo011`
> 总览：[011 metadata011 体系](011.topic-metadata011-system.md)；上级：[021 MetaData011](013.topic-metadata011.md)。

## 011.定位

`ServiceInfo011` 是 `MetaData011` 聚合内的**服务定义**：对象上可执行的一组「动作/方法」（增删改查、导入导出、发布菜单，或自定义 SQL/脚本），描述「**能做什么**」。

## 013.组成

| 字段 | 说明 | 约束 |
|------|------|------|
| `serviceCode` | 服务编码（**身份，不可变**，聚合内唯一） | 必填，≤60 |
| `serviceName` | 服务名称 | 必填，≤60 |
| `serviceDescription` | 描述 | ≤300 |
| `objectType` | 服务对象类型（`ServiceObjectType011`） | null 默认 global |
| `paramType` | 参数类型（`ServiceParamType011`） | null 默认 none |
| `serviceContent` | SQL / 脚本内容 | 必填，≤**20000** |
| `enabled` | 是否启用 | boolean（`enable()/disable()`） |

## 015.枚举

**`ServiceObjectType011`**
| 值 | 含义 |
|----|------|
| `global_method` | 全局方法（默认） |
| `table_row_method` | 行方法（针对单行） |

**`ServiceParamType011`**
| 值 | 含义 |
|----|------|
| `none` | 无参（默认） |
| `string` | 字符串参数 |
| `object` | 对象参数 |
| `single_file` | 单文件上传 |
| `multi_file` | 多文件上传 |

## 017.不变式与工厂

- `create(serviceCode, serviceName, serviceDescription, objectType, paramType, serviceContent)`；`serviceCode` 不可变；`serviceContent` 必填 ≤20000。
- `updateBasics(serviceName, serviceDescription, objectType, paramType, serviceContent)`；`enable()/disable()` 切换启用。
- 访问器：`serviceCode()/serviceName()/serviceDescription()/objectType()/paramType()/serviceContent()/enabled()`。

## 019.在体系中的角色

- **默认服务集**（建房/播种时常见）：`insert / update / delete / query`（+ 可选 `import / export / publishMenu`）。
- **运行时**：前端按 `serviceData` 决定显示哪些操作按钮；实际执行落 `runtime/v1/{insert,update,delete,query}` 或开放 API。
- **只描述不生成**：本期不生成服务代码，`serviceContent` 为预留（自定义 SQL/脚本）。

## 021.与 MetaDTO

`serviceData` 段即 `services`：`{ code, name, description, objectType, paramType, serviceContent, enabled, sort }`。
