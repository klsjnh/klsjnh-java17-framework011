# 032.topic-template（元数据模板 · 取/导/审/部署）

> 低代码知识库 · 模板（040）
> 总览：[011](011.topic-metadata011-system.md)；契约：[026 MetaDTO](019.topic-metadata-dto.md)；方案：[req013/040](../requirement013/040.topic-metadata-template.md)。

## 011.定位

模板 = **自包含 JSON**（MetaDTO + `source` + `templateVersion` + `_guide`）：可取默认骨架、导出对象、**上传审核（零副作用）**、**部署（落库 + 发布）**。给 AI/外部工具一个声明式入口。

## 013.端点（`/klsjnh/lowcode011/julyMetadata/v1`）

| 端点 | 方法 | 入参 | 说明 |
|------|------|------|------|
| `/getTemplate011` | GET | — | 默认骨架（`_guide` 代注释） |
| `/downloadTemplate011` | GET | `objectName` | 导出（1 主 3 子 + `source`） |
| `/uploadTemplate011` | POST | **multipart `file`** 或 JSON | **审核**：校验 + `previewDdl` + `plan`，**不落库** |
| `/deployObject` | POST | `{template|objectName, overwrite?}` | 落库 + 发布 |

## 015.校验（审核与部署共用）

- `objectName`：`^[a-z][a-z0-9_]{0,49}$`。
- 子 `code` **大小写不敏感唯一**（同时拦"业务字段重名基列"）。
- 基列**允许一次**、类型归一；`businessField` 非基列且 `string(33)`；`pk_*` `string(33)`。
- `fieldType`/`objectType` 过枚举；`display.code` 必须绑字段。
- 失败整单拒绝；`overwrite=false` 且已存在 → 400。

## 017.形态

```json
{ "templateVersion":"1.0", "_guide":{...},
  "metaData":{ "objectName":"...", "source":{ "dataSourceCode":"bpm011", "probeSql":"..." } },
  "fieldData":[...], "displayData":[...], "serviceData":[...] }
```
- `source` 由 `deployObject` 持久化到 `july_metadata.data_source_code/probe_sql`，`downloadTemplate011` 原样带回。
- 模板**不落库**（靠 `july_metadata_version` 快照复现）。

## 019.推荐流程（AI 场景）

`getTemplate011`（或 `downloadTemplate011`）→ 填/改 → `uploadTemplate011` 看 `errors`+`previewDdl`+`plan` → **人确认** → `deployObject` →（可选）`importDataFromSql`。

## 021.边界

批量 `templates[]` 未做；模板→代码/页面未做；跨环境迁移未做。
