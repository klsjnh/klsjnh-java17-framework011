# 033.topic-dictionary-field（字典字段 · dictionary011 / dictionary013 + param011）

> 低代码知识库 · **核心架构变更（草稿，待实现）**
> 基础：[022 FieldInfo011](015.topic-fieldinfo.md)（FieldType011 逐个）/ [023 DisplayInfo011](016.topic-displayinfo.md)。
> 决策：命名**不缩写**（全称 `dictionary011` / `dictionary013`）；依赖形态 **A**（直接注入 `JulyDictionaryUseCase`）；校验软/硬暂缓。

## 011.需求

字段需要「字典」能力，两种来源：
- **`dictionary011`（自定义字典）**：选项内联在字段自身（`param011`）；
- **`dictionary013`（系统字典）**：引用 system011 的字典（`param011` = 字典编码）。

## 013.类型与属性

| 项 | 约定 |
|----|------|
| `FieldType011` 新增 | `DICTIONARY011("dictionary011")` / `DICTIONARY013("dictionary013")`（业务列） |
| `FieldInfo011` 新增 | `param011`（参数011，扩展参数；与 `DisplayInfo011.param011` 同名同义） |
| 物理列 | `VARCHAR(length)`（值语义是 int，但按 string 落；缺省口径同 `string`：0/超限→255） |

## 015.`param011` 语义

| 类型 | `param011` 内容 | 示例 |
|------|-----------------|------|
| `dictionary011` | 选项串：`值|标签` 以 `;` 分隔 | `1|是;2|否` |
| `dictionary013` | **字典编码**（`july_dictionary.dictionary_code`） | `SEX` |
| 其他类型 | null | — |

**选项语法（dictionary011）**
- 分隔：`;` 分项，`|` 分「值 / 标签」。
- **值 / 标签均不允许包含 `|` 或 `;`**（定案）。
- 值：语义 int，落字符串（`"1"`）。
- 标签：暂定必填。

## 017.`dictionary013` 与系统字典（依赖形态 A）

直接注入 `JulyDictionaryUseCase`（app→app）：

| 用途 | 方法 |
|------|------|
| 校验值域 | `isValidItem(dictionaryCode, itemCode)` |
| 取标签 | `getLabel(dictionaryCode, itemCode)` |
| 选项列表 | `selectItemListByType(dictionaryCode, status)` |

- 前端渲染直接调现有 HTTP：`POST /klsjnh/system011/julyDictionary/v1/selectItemListByType`（`{dictionaryCode, status}`）。
- 低代码侧**不新增字典接口**。
- 校验软/硬：**暂缓**（字典缺失的处理后续再定）。

## 019.前端渲染

| 类型 | 控件 | 选项来源 |
|------|------|----------|
| `dictionary011` | `select`/`radio` | 解析字段 `param011` |
| `dictionary013` | `select`/`radio` | 系统字典（缓存） |

列表通常渲染**标签**（值→label），表单渲染**下拉/单选**。详见 [023](016.topic-displayinfo.md) §023。
