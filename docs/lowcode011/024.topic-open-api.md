# 031.topic-open-api（开放 API · api_key 公共 CRUD + meta）

> 低代码知识库 · 开放 API（039 三期）
> 总览：[011](011.topic-metadata011-system.md)；运行时对照：[030](023.topic-runtime.md)；方案：[req013/039](../requirement013/039.topic-lowcode-designer-runtime.md)。

## 011.定位

开放 API = 把**已发布对象**以 **`api_key` 鉴权**对外暴露：查询元信息 + 数据 CRUD，供第三方/外部系统（或 AI）调用，**无需 JWT**。

## 013.配置（管理端，JWT，挂 `/klsjnh/lowcode011/julyMetadata/v1`）

| 端点 | 方法 | 说明 |
|------|------|------|
| `/openApiConfig` | GET | `?objectName=` 读配置（apiKey 打码 `****xxxx`） |
| `/saveOpenApiConfig` | POST | `{objectName, enabled, authMode(closed/none/apiKey), allowedOps[]}`；首次生成 apiKey 回明文一次 |
| `/rotateApiKey` | POST | `{objectName}` 轮换，回明文一次 |

## 015.开放端（`X-Api-Key`，`/klsjnh/open/v1`，JWT 白名单）

| 端点 | 方法 | 说明 |
|------|------|------|
| `/meta` | GET | `?objectName=` 对象元信息（MetaDTO） |
| `/query` | POST | `{objectName, filters, pageIndex, pageSize}` |
| `/insert` | POST | `{objectName, ...列}` |
| `/update` | POST | `{objectName, id|sid, ...列}` |
| `/delete` | POST | `{objectName, id|sid}`（有 `dr` 逻辑删） |

## 017.鉴权与规则

- 鉴权顺序：配置存在且 `enabled` → `authMode=apiKey` 校验 `X-Api-Key` → `allowedOps` 含当前操作；不通过 **401**。
- 仅**已发布**对象；表/列以库表目录为白名单；值全绑定；`insert` 补基列默认。
- apiKey：32 位 hex；读打码；生成/轮换明文仅回一次。
- **挂起**：限流 / CORS / 行级权限。

## 019.代码位置

`JulyMetadataOpenApiUseCase`（配置）+ `OpenApiUseCase`（公共面）+ `JulyMetadataOpenApiController` / `OpenApiController`；`GlobalAuthFilter` 白名单 `/klsjnh/open/`。
